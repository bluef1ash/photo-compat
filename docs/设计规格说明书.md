# 1. 设计目标

## 1.1 产品定位

照片适配助手是一把**只做一件事**的桌面工具:把一个文件夹里的照片,批量变成老旧政务、医疗、教育系统能上传的标准 JPEG。

它做的事:移除拍摄信息（EXIF）、移除颜色配置（ICC）、自动修正方向、转为基础式 JPEG（Baseline）、转换 HEIC、限制最大宽高、统一 sRGB 色彩空间。

它**不做**的事:不是图像编辑器,不是云相册,不是 AI 工具,不提供修图、滤镜、拼图、识别。

软件**完全离线**:不联网、不调用 AI、不上传任何数据、不需要账号。定位四个关键词:**简单、可靠、稳定、兼容**。

## 1.2 用户画像

| 画像                    | 特征                                 | 设计含义                                           |
| ----------------------- | ------------------------------------ | -------------------------------------------------- |
| 主:政务/医疗/教育办事员 | 大量中老年、视力受限、计算机水平一般 | 大字号、高对比、去技术化文案、单一主路径、强安全感 |
| 次:单位 IT/信息员       | 需在多台电脑统一部署                 | 预留配置导入导出、命令行模式(未来)                 |
| 边界:临时使用人员       | 一年用几次,记不住操作                | 默认值即可完成全流程,无需学习                      |

## 1.3 核心任务

端到端一条线:选择目录 → 扫描统计 → 处理转换 → 输出到子目录 → 打开输出目录。用户全程只关心三件事:**照片从哪来、变成什么、结果在哪**。

## 1.4 设计原则

四条主线,任何交互实现不得违背。

| 原则         | 含义                                     | 设计后果                                                        |
| ------------ | ---------------------------------------- | --------------------------------------------------------------- |
| **确定性**   | 每个动作都有可预测结果,绝不"惊喜"        | 处理前显示预估数量与体积;处理中显示进度;处理后显示明确清单      |
| **安全感**   | 默认绝不破坏原始数据                     | 默认输出到子目录、默认不覆盖、默认保留结构;危险操作永远二次确认 |
| **诚实**     | 不夸大能力,不静默跳过                    | 不支持的格式、损坏文件、失败项全部显式告知并记录到日志          |
| **极简心智** | 用户只关心"传哪儿、点哪儿、在哪儿看结果" | 单一主路径、无侧栏、无多标签、无专业术语                        |

## 1.5 易用性原则

1. **三次点击原则（上限,非目标）**:从打开应用到打开输出目录,核心操作不超过 3 次点击;拖拽路径压到 2 次。任何把步骤加到 4 次以上的设计都要被质疑。
2. **单一主行动（One Primary Action）**:每个屏幕有且只有一个视觉权重最高的主按钮;其余操作降级为次按钮或微妙按钮。
3. **渐进披露（Progressive Disclosure）**:首页只给"拖进来 / 选文件夹";统计、警告、设置按需展开;高级选项永远不挡主路径。
4. **可读性优先于美观**:字号偏大、间距偏宽、对比偏高;为视力下降的中老年办事员优化,而非为设计师审美优化。
5. **离线即信任**:界面任何位置不出现"登录、云、上传、AI、智能"等字样;状态栏常驻"离线"标识。

## 1.6 成功标准（可量化）

| 指标           | 目标值                                               |
| -------------- | ---------------------------------------------------- |
| 核心流程点击数 | ≤ 3 次(选择路径);拖拽路径 ≤ 2 次                     |
| 默认值完成度   | 不打开设置即可完成主流程 100%                        |
| 文字对比度     | 正文 ≥ 4.5:1,大字 ≥ 3:1（WCAG AA）                   |
| 键盘可达率     | 100% 操作有键盘等价                                  |
| 异常显式告知率 | 不支持格式 / 损坏 / 失败 / 跳过 = 100% 告知 + 记日志 |
| 离线可信度     | 全界面 0 处出现"登录/云/上传/AI/智能"字样            |
| 原始数据安全   | 默认 0 覆盖(输出到子目录、保留结构)                  |

# 2. 信息架构（Information Architecture）

## 2.1 三层结构总览

心智模型自上而下三层,视觉权重递减。

```
┌─────────────────────────────────────────────┐
│  主流程区(视口主体)                           │
│  选目录 → 扫描结果 → 处理 → 完成              │
│  任何时候占据 70% 以上视觉权重                 │
├─────────────────────────────────────────────┤
│  配置区(设置页,按需打开)                       │
│  通用 / 输出 / 兼容性 / 性能 / 外观 / 高级      │
│  默认值即可完成主流程,无需主动配置              │
├─────────────────────────────────────────────┤
│  辅助区(状态栏 + 通知 + 日志)                  │
│  当前状态、兼容模式、就绪/离线标识、Toast        │
└─────────────────────────────────────────────┘
```

**关键决策**:不使用常驻侧栏。这是线性流水线工具,不是多功能应用。常驻侧栏会制造"还有别的功能没看到"的认知负担,违背极简心智。

## 2.2 页面层级树

```
应用根窗口
├─ 标题栏(常驻)
│   ├─ 左:Logo + "照片适配助手"
│   ├─ 中:拖拽区
│   └─ 右:兼容模式徽章 + ⋯ 溢出菜单 + 系统控件
├─ 步骤条(主流程进行时显示)
│   ① 选目录 → ② 查看结果 → ③ 处理 → ④ 完成
├─ 主内容区(随步骤切换,5 个主视图)
│   ├─ 首页(含扫描过渡态)
│   ├─ 扫描结果
│   ├─ 处理中(含已暂停态)
│   ├─ 完成
│   └─ 设置(独立页,左导航 + 右设置项)
├─ 状态栏(常驻)
│   左:就绪/处理中/扫描中 · 中:兼容模式·输出位置 · 右:离线·版本号
└─ 浮层系统(按需)
    ├─ 模态对话框(ContentDialog)
    ├─ Toast(右下角)
    ├─ Flyout 浮层(菜单、快速设置、最近目录)
    └─ Tooltip
```

> **注**:文件夹选择不单独成页,直接调用系统原生选择器(见 §5.2)。错误对话框、不支持格式对话框、关于页为模态/浮层形态,在 §5.7–§5.9 详述。

## 2.3 主流程状态机

```
        ┌──────── 首页 ────────┐
        │                      │
        ▼                      │
    扫描中 ──失败──► 错误对话框 ─┘
        │
        ▼
    扫描结果 ◄──修改设置──► 设置页
        │
   开始处理
        ▼
    处理中 ──暂停──► 已暂停 ──继续──► 处理中
        │
   完成/取消
        ▼
    完成页 ──处理另一个──► 首页
```

**状态迁移规则**:
- 步骤可**回退**(点已完成步骤或按 Esc 返回)。
- 步骤**不可跳跃前进**(未扫描不能直接处理)。
- 处理进行中**不可静默回退**(需经取消确认对话框)。

## 2.4 页面跳转矩阵

| 起点     | 终点         | 触发                                                 |
| -------- | ------------ | ---------------------------------------------------- |
| 首页     | 扫描中       | 拖入文件夹 / 点[选择文件夹]选定 / 点最近文件夹[继续] |
| 扫描中   | 扫描结果     | 扫描完成且有可处理图片                               |
| 扫描中   | 首页         | 扫描失败(错误对话框后) / 0 张(空状态[重新选择])      |
| 扫描结果 | 处理中       | 点[开始处理] / 按 Enter                              |
| 扫描结果 | 首页         | 点[取消] / 按 Esc                                    |
| 扫描结果 | 设置页       | 点[修改]链接(快速设置 Flyout)或溢出菜单              |
| 处理中   | 已暂停       | 点[暂停] / 按 Space                                  |
| 已暂停   | 处理中       | 点[继续] / 按 Space                                  |
| 处理中   | 完成         | 全部处理完毕                                         |
| 处理中   | 完成(取消态) | 取消确认后                                           |
| 完成     | 首页         | 点[处理另一个文件夹] / 按 Ctrl+N                     |
| 任意     | 设置页       | 溢出菜单[设置] / Ctrl+,                              |
| 任意     | 关于页       | 溢出菜单[关于] / F1                                  |

## 2.5 入口与出口

- **入口**:
  - 启动应用 → 首页。
  - 拖入文件夹 / 选定文件夹 / 点最近文件夹 → 自动进入扫描(无需点确认)。
- **出口**:
  - 完成页[打开输出目录](主出口,用户最想要的下一步)。
  - 完成页[处理另一个文件夹] → 回首页。
  - Ctrl+Q / 关闭按钮 → 退出(处理中需经关闭确认)。

✅ **验收要点**:
- 主内容区同一时刻只显示 1 个主视图,无标签页切换。
- 步骤条未到达的步骤不可点击前进。
- 任何主流程状态均可经一次操作回退到上一步(处理中除外,需确认)。
- 状态栏在所有视图常驻显示。

# 3. 窗口规范

## 3.1 窗口标题与标识

- **标题栏高度**:40px。
- **结构**:左侧 Logo(专用矢量图标)+ 应用名"照片适配助手";中部留空作为拖拽区;右侧依次为兼容模式徽章(如"标准兼容模式")+ `⋯` 溢出菜单按钮 + 系统窗口控件(最小化/最大化/关闭)。
- **装饰**:默认**应用自绘统一标题栏**,三端外观一致;提供"使用系统原生标题栏"开关,供 Linux CSD/SSD 桌面或用户偏好原生装饰时回退。
- **交互**:双击标题栏拖拽区 = 最大化/还原。
- **禁用**:界面任何位置不出现"登录/云/AI"字样;Logo 使用专用矢量图标(非表情符号)。

## 3.2 默认尺寸与最小尺寸

| 项           | 值                                                |
| ------------ | ------------------------------------------------- |
| 默认尺寸     | 1100 × 720(落在标准档 960–1280 区间)              |
| 最小尺寸     | **880 × 640**(保证核心元素不挤压、不溢出、不重叠) |
| 内容最大宽度 | 1200px(宽屏居中,两侧留白,防止行宽过长)            |

## 3.3 窗口缩放规则（三档断点）

桌面"响应式"= 窗口缩放自适应,非移动端断点。

| 窗口宽度           | 布局调整                                                       |
| ------------------ | -------------------------------------------------------------- |
| `< 960px`(紧凑)    | 统计卡 4 列 → 2 列;设置左侧导航折叠为顶部下拉;标题栏应用名截断 |
| `960–1280px`(标准) | 默认布局,推荐工作区                                            |
| `> 1280px`(宽屏)   | 内容区最大宽 1200px 居中,两侧留白                              |

- **字号缩放**:跟随"大字号"设置整体 ×1.25(大)/ ×1.5(超大),布局自适应不溢出、不裁切。
- **禁令**:任何宽度下不得出现横向滚动条;大数字、长文件名溢出一律截断 + Tooltip 显示全文。

## 3.4 高 DPI 显示

| 平台    | 缩放支持                                                     |
| ------- | ------------------------------------------------------------ |
| Windows | 100% / 125% / 150% / 200%,文字图标清晰锐利                   |
| Linux   | 跟随 X11 分数缩放或 Wayland 缩放因子,自测 100% / 125% / 150% |

## 3.5 窗口状态保持

- 记住上次窗口位置、大小、主题,下次启动恢复。
- 主题默认"跟随系统"。

## 3.6 多显示器行为

- 在上次记录的显示器上恢复窗口。
- 若该显示器已断开,回退到主显示器,尺寸取默认值(1100 × 720)。

## 3.7 关闭规则

| 场景       | 行为                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 非处理中   | 直接退出(若设置开启"最小化到托盘"则驻留托盘)                             |
| 处理进行中 | 弹关闭确认对话框:"处理尚未完成(已完成 X%),确定退出吗? [继续处理] [退出]" |
| 已暂停     | 同"处理进行中"                                                           |

- 默认焦点落在[继续处理](最鼓励的操作)。
- 遮罩点击不关闭;Esc = 继续处理(取消关闭)。

## 3.8 最大化行为

- 内容居中限宽(最大 1200px),不铺满导致行宽失控。
- 统计卡网格、列表在大宽度下保持可读行宽。

## 3.9 单实例

- 再次启动应用:**激活已有窗口**(置于前台并聚焦),不开启第二实例。

## 3.10 平台差异（窗口层）

| 行为     | Windows 10 / 11                                              | Linux(含信创)                                                         |
| -------- | ------------------------------------------------------------ | --------------------------------------------------------------------- |
| 标题栏   | 默认自绘,保留系统圆角顶角与最小化/最大化/关闭控件;双击最大化 | 默认自绘 CSD 控件;提供"系统原生标题栏(SSD)"开关适配 GNOME/KDE/UOS/DDE |
| 窗口背景 | Win11 启用 Mica(透出桌面壁纸柔和色调);Win10 降级纯色背景     | 不支持 Mica,统一纯色背景 + 卡片表面提升对比                           |
| DPI 缩放 | 100/125/150/200%                                             | 跟随 X11 分数缩放 / Wayland 因子                                      |

✅ **验收要点**:
- 窗口不可缩放到小于 880 × 640。
- 任何宽度下无横向滚动条。
- 处理中关闭必弹确认对话框,默认焦点为"继续处理"。
- 第二次启动激活已有窗口,不出现两个实例。
- 宽屏下内容区宽度不超过 1200px。

# 4. 导航规范

## 4.1 导航方式

| 导航对象               | 承载方式                        |
| ---------------------- | ------------------------------- |
| 主流程 4 步            | 顶部步骤条                      |
| 设置 / 关于 / 日志     | 右上 `⋯` 溢出菜单               |
| 设置内部 6 分组        | 设置页左侧分组导航 + 顶部搜索框 |
| 返回 / 取消 / 关闭浮层 | Esc(最强安全出口)               |

- **无常驻侧栏**(违背极简心智,制造"还有别的功能"的认知负担)。
- **无多标签页**(线性流水线,同一时刻只有一个主任务)。

## 4.2 步骤条规则

- 四步:① 选目录 → ② 查看结果 → ③ 处理 → ④ 完成。
- **已完成**:对勾图标 + 强调色。
- **当前**:强调色实心数字。
- **未到达**:灰色数字。
- **可点已完成步骤回退**;**不可点未到达步骤前进**。
- 当前步骤下方可显示子进度(如"③ 处理 68%")。

## 4.3 返回规则

- 任意步骤按 Esc 或点已完成步骤可回退。
- 处理进行中**不可静默回退**,需经取消确认对话框(见 §8.5)。

## 4.4 关闭规则

见 §3.7(窗口关闭)与 §4.6(Esc 浮层关闭)。

## 4.5 确认规则

- **危险操作必二次确认**:取消处理、覆盖已存在文件、重置所有设置、处理中关闭窗口。
- **模态对话框遮罩点击不关闭**(防误触),需显式点按钮或 Esc。

## 4.6 键盘导航总表

| 快捷键              | 作用域 | 功能                                   |
| ------------------- | ------ | -------------------------------------- |
| `Ctrl+O`            | 全局   | 选择文件夹                             |
| `Ctrl+,`            | 全局   | 打开设置                               |
| `Ctrl+L`            | 全局   | 打开日志文件                           |
| `Ctrl+E`            | 完成页 | 导出日志                               |
| `Ctrl+N`            | 完成页 | 处理另一个文件夹                       |
| `Ctrl+F`            | 设置页 | 搜索设置项                             |
| `Ctrl+1` ~ `Ctrl+5` | 首页   | 打开第 1–5 个最近文件夹                |
| `Ctrl+Q`            | 全局   | 退出                                   |
| `F1`                | 全局   | 关于 / 本地帮助                        |
| `Space`             | 处理中 | 暂停 / 继续                            |
| `Enter`             | 各页   | 激活主行动(开始处理 / 打开目录 / 继续) |
| `Esc`               | 全局   | 返回上一步 / 取消当前操作 / 关闭浮层   |
| `Tab` / `Shift+Tab` | 全局   | 焦点前/后移                            |

**作用域约束**:所有快捷键仅在**窗口激活态**生效;后台或失焦时不注册全局快捷键(规避 Wayland 权限复杂度)。所有快捷键均有等价的鼠标/触摸操作,不强制记忆。

## 4.7 焦点顺序

- **逻辑 Tab 顺序**:左上 → 右下,符合阅读顺序。
- **可见焦点环**:2px 强调色 + 2px 偏移(offset),不依赖颜色;在"减少动画"开启时焦点环不消失。
- **模态内循环**:对话框打开后,焦点默认落主按钮,Tab 在对话框内循环,不跳出到背景。
- **激活后回归**:对话框/Flyout 关闭后,焦点回到触发它的控件。

✅ **验收要点**:
- 步骤条未到达步骤点击无响应。
- 任何浮层可经 Esc 关闭。
- Tab 顺序符合视觉阅读顺序(左上→右下),无跳跃。
- 焦点环在所有状态下可见(含"减少动画"开启时)。
- 危险操作全部经二次确认。
- 全局快捷键仅在窗口激活态生效。

## 5.2 屏幕二 · 文件夹选择 Folder Selection

**目的 / 用户目标**:让用户指定目录,提供"系统选择器"和"最近列表"两条路径。

**形态说明**:本屏**不单独占据整页**。点击[选择文件夹]直接调用**各平台原生文件夹选择器**(Windows = Win32 FolderPicker;Linux = GTK FileChooser),保证用户对系统选择器的熟悉感。最近文件夹的快捷选择已内嵌在首页。

**校验流程**:FolderPicker 选定 → 立即校验可读 → 通过则扫描;该目录无可处理图片 → 轻量 Flyout"这个文件夹里没有可处理的照片" + [重新选择]。

**状态**:

| 状态                    | 表现                                               |
| ----------------------- | -------------------------------------------------- |
| 空(无最近文件夹)        | [选择文件夹]下方提示"也可以直接把文件夹拖到窗口里" |
| 加载                    | 选定后立即扫描,进入扫描过渡态                      |
| 错误(权限不足/目录无效) | 见 §5.7 错误对话框                                 |

**键盘**:Ctrl+O 打开选择器;Esc 取消选择器;Enter 在选择器中确认。

**设计原因**:复用系统原生选择器,降低"陌生软件"戒备,且免去自研选择器的维护成本。

✅ **验收要点**:
- 点击[选择文件夹]弹出系统原生选择器(非应用自绘)。
- 选择器取消后回首页,无副作用。
- 选定空目录(无可处理图片)弹出轻量 Flyout 而非进入扫描结果。

## 5.3 屏幕三 · 扫描结果 Scan Result

**目的 / 用户目标**:处理前让用户清楚"会发生什么"——处理多少、产出多大、有无问题。**确定性原则的关键落点**。

**布局**:

1. 步骤条:① 选目录 ✓ → ② 查看结果(当前)。
2. 标题区:"扫描完成"(title)+ 源目录路径 + "← 重新选择"链接。
3. **统计卡网格**(4 列,窄屏 2 列):总图片数 `230` / 预计输出数量 `230` / 预计输出大小 `约 48 MB` / 预计节省 `减少 12 MB`。
4. **格式分布卡**:每格式 = 图标 + 名称 + 数量 + 横条;JPEG 标"无需转换",PNG/HEIC/WebP/TIFF 标"将转换"。
5. **兼容性问题与警告**(InfoBar 列表):🟡 检测到 8 张 HEIC,将自动转换;🟡 15 张 PNG 体积较大;🔴 3 张疑似损坏,将跳过并记日志。
6. **输出设置快览**:输出到「同目录/compat」· 保留结构 · 不覆盖 · 质量 90 + [修改]链接(弹 Flyout,不离开页面)。
7. 底部操作栏(sticky):左"共 230 张,预计输出约 48 MB" | 右 [开始处理] Primary + [取消] Secondary。

**主要 / 次要操作**:[开始处理](Primary)、[取消](Secondary)、[重新选择](链接)、[修改]输出设置(Flyout)、点格式徽章展开子列表、点警告展开详情。

**状态**:

| 状态                          | 表现                                                            |
| ----------------------------- | --------------------------------------------------------------- |
| 空(扫描 0 张)                 | 居中"这个文件夹里没有可处理的照片" + 大图标 + [重新选择文件夹]  |
| 加载(扫描中)                  | 环形进度 + "正在扫描… 已发现 N 张"(实时刷新计数)                |
| 错误(扫描失败,如中途权限丢失) | 居中错误卡 + [重试扫描]                                         |
| 有不支持格式                  | 警告 InfoBar"检测到 N 个暂不支持的文件" + [点击查看](进入 §5.8) |

**键盘**:Enter 开始处理;Esc 返回首页;Tab 遍历统计卡与警告。

**设计原因**:用"处理前预估"兑现确定性,把意外(HEIC、损坏、不支持)前置告知,避免处理后才发现。

✅ **验收要点**:
- 4 个统计卡数字使用等宽对齐,不跳动。
- 格式分布横条宽度按各格式数量占比。
- HEIC/PNG/损坏等异常均有对应 InfoBar,不静默。
- 底部操作栏在内容滚动时保持可见(sticky)。
- 扫描到 0 张时显示空状态而非空表格。

## 5.4 屏幕四 · 处理中 Processing

**目的 / 用户目标**:让用户安心等待,清楚进度与健康度。

**布局**:

1. 步骤条:①✓ ②✓ → ③ 处理中(带子进度)。
2. **大进度区**(主视觉):大百分比 `68%`(display-num 56px 等宽)+ 线性进度条(8px 全宽强调色)+ 副文字"已处理 156 / 230"。
3. 当前文件行:缩略图 40×40 + 文件名(截断,Tooltip 全名)+ 当前操作徽章"转换 HEIC → JPEG"。
4. **实时统计**(6 个统计卡):已用时间 `00:42` / 预计剩余 `01:20` / 速度 `3.6 张/秒` / 已处理 `156` / 失败 `0`(>0 变红可点)/ 跳过 `0`(>0 变灰可点)。
5. **实时日志**(可折叠面板):默认折叠为一行"最新:[14:23:05] 转换 IMG_0123.HEIC → JPEG ✓";展开后为滚动列表,等宽 12px,带时间戳与状态色。
6. 底部操作栏:[打开日志文件](Subtle)| [取消](Destructive)| [暂停](Secondary,暂停后变[继续])。

**状态**:

| 状态                      | 表现                                                    |
| ------------------------- | ------------------------------------------------------- |
| 进入瞬间(<200ms)          | "准备中…"不确定进度条,再切确定进度                      |
| 暂停                      | 进度条变灰、计数暂停、按钮变[继续]、状态栏"已暂停"      |
| 失败计数 >0               | 失败统计卡高亮红,点击弹出失败清单                       |
| 失败超阈值(>5% 或 >20 张) | 顶部黄色 InfoBar"失败较多,建议查看日志后再决定是否继续" |
| 单文件失败                | 记日志 + 失败计数 +1,不中断主流程                       |
| 致命错误(磁盘满等)        | 错误对话框 + 停止 + 跳完成页(未完成态)                  |

**取消交互**:[取消] → 确认对话框"已处理的 156 张会保留在输出目录,确定取消吗?"→ 是则停止并跳完成页(带"已取消"标记)。

**键盘**:Space 暂停/继续;Esc 触发取消确认;Ctrl+L 打开日志文件;Tab 切换按钮。

**设计原因**:大数字 + 大进度条 + 实时日志三层,让等待可感知、可监督;单文件失败不中断主流程,兑现"诚实但不打断"。

✅ **验收要点**:
- 进度百分比与进度条、已处理计数三者同步。
- 暂停后所有计数停止,按钮文字变为[继续]。
- 单文件失败不中断整体处理。
- 失败超阈值时黄色 InfoBar 出现。
- 日志面板可折叠/展开,折叠态显示最新一行。

## 5.5 屏幕五 · 完成 Completed

**目的 / 用户目标**:明确告知成功,提供清晰下一步。克制给正向反馈。

**布局**:

1. 步骤条:①✓ ②✓ ③✓ → ④ 完成。
2. 成功状态(居中):大对勾图标 72px(强调色或成功色,单次绘制动画 300ms 仅一次)+"处理完成!"(large-title)+ 副标"227 张照片已转换为兼容格式"。
3. **结果统计卡**(4 列):总计处理 `230` / 成功 `227`(成功色)/ 失败 `0`(>0 黄色可点)/ 跳过 `3`(灰色可点)。
4. 兼容模式摘要卡:"标准兼容模式:JPEG 质量 90 · 去除 EXIF/ICC · 修正方向 · 转换 HEIC · 限制 4096px"。
5. 输出位置卡:路径(等宽,可点击选中)+ "已保留原文件夹结构 · 共 227 个文件 · 约 48 MB"。
6. 底部操作栏:**[打开输出目录]**(Primary,最高优先级)| [导出日志](Secondary)| [处理另一个文件夹](Secondary)。

**状态**:

| 状态                 | 表现                                                                   |
| -------------------- | ---------------------------------------------------------------------- |
| 正常完成             | 绿色对勾 + 成功统计                                                    |
| 有失败/跳过          | 多一个[查看失败/跳过列表]按钮,弹对话框显示文件名 + 原因 + [复制列表]   |
| 整体失败(磁盘满中断) | 红色"处理未完成"状态 + 已处理部分 + 失败原因 + [重试] + [打开部分输出] |
| 窗口非聚焦时完成     | 系统托盘通知 + 任务栏闪烁(可设置关)+ 完成提示音(可设置关)              |

**键盘**:Enter / Ctrl+O 打开输出目录;Ctrl+E 导出日志;Ctrl+N 处理另一个文件夹。

**设计原因**:[打开输出目录]设为 Primary,因为这是用户处理完最想要的下一步;对勾动画仅一次,避免常驻脉冲(违克制原则)。

✅ **验收要点**:
- [打开输出目录]为视觉权重最高的 Primary 按钮。
- 对勾绘制动画仅播放一次,不循环。
- 调用系统资源管理器打开输出目录(Windows 资源管理器 / Linux xdg-open)。
- 失败/跳过 >0 时出现[查看列表]按钮。
- 窗口非聚焦完成时触发托盘通知 + 任务栏闪烁(除非设置关闭)。

| 高级   | 临时目录                    | 浏览框   | 系统临时          | 处理中转目录,建议留足空间          |
| 高级   | 导出 / 导入配置             | 按钮     | —                 | 便于备份/统一部署                  |
| 高级   | 重置所有设置                | 危险按钮 | —                 | 恢复默认,二次确认                  |

**架构自适应默认值**(程序按 CPU 架构自动选择,用户可手动覆盖;**不暴露架构选择给用户**):

| 设置项       | x86_64 / 通用 | ARM(鲲鹏/飞腾)/ LoongArch(龙芯) |
| ------------ | ------------- | ------------------------------- |
| 并行处理数   | CPU 核心数    | min(核心数, 4),留 1 核给系统    |
| 内存上限     | 系统内存 75%  | 系统内存 50%                    |
| 大图采样缩放 | 开(可关)      | **强制开,不可关**(防内存溢出)   |

- 性能页并行数旁显示自动检测说明,如"检测到龙芯 LoongArch 架构,已设为 4(可调)"。
- 用户手动调高时给温和提示"当前架构性能有限,过高可能导致卡顿"。

**状态**:

| 状态                    | 表现                              |
| ----------------------- | --------------------------------- |
| 空(搜索无果)            | "没有匹配的设置项"                |
| 即时保存                | 改动即生效 + 右下角"已保存"微提示 |
| 危险操作(重置/覆盖输出) | 二次确认对话框                    |
| 导入配置格式错误        | Toast"配置文件无效,未导入"        |

**键盘**:Ctrl+F 搜索;Tab 遍历设置项;Esc 关闭设置。

**设计原因**:设置项按"标题+描述+控件"行模式统一,降低认知负担;即时保存 + 撤销免去"忘记点保存"的焦虑。

✅ **验收要点**:
- 改动任一设置项立即生效,出现"已保存"微提示。
- 搜索框实时过滤,无结果显示空状态。
- 重置/覆盖类危险操作必经二次确认。
- 性能默认值随 CPU 架构自动变化,且不向用户暴露架构选择。
- ARM/LoongArch 架构下大图采样缩放不可关闭。

## 5.7 屏幕七 · 错误对话框 Error Dialog

**目的 / 用户目标**:把"出错了"转化为"怎么办"。永远给出可操作解决路径,不展示令用户恐慌的技术堆栈。

**统一模板**(ContentDialog):

```
┌─ [错误图标 红]  无法读取这个文件夹 ──────┐
│  问题:选定的文件夹无法被读取。          │
│  可能原因:                              │
│  · 文件夹已被移动或删除                  │
│  · 被其他程序锁定                        │
│  · 系统权限不足                          │
│  建议尝试:                              │
│  1. 确认文件夹仍然存在                   │
│  2. 关闭可能占用它的程序                 │
│  3. 重新选择文件夹                       │
│              [打开帮助]  [重新选择]  [关闭] │
└─────────────────────────────────────────┘
```

**结构契约**:每个错误对话框必含 **问题 / 原因 / 解决 / 按钮** 四段。

**形态**:居中,8px 圆角,宽 448–548px;遮罩 `rgba(0,0,0,0.3)`,遮罩点击**不关闭**;焦点默认主按钮;Tab 在对话框内循环;出现/消失 200ms 缩放+淡入(减少动画可关)。

**按钮规则**:主按钮(最右)= 最鼓励的操作(重试/重新选择);次按钮 = 退出/关闭;可选[打开帮助](本地手册)。

**完整错误矩阵**见 §8(弹窗规范):目录不可访问 / 权限不足 / 磁盘已满 / 不支持图片 / 损坏图片 / 未知错误 / 用户取消。

**键盘**:Esc 关闭/取消;Enter 主按钮;Tab 按钮间循环。

**设计原因**:四段结构(问题/原因/解决/按钮)把"出错了"转为可执行步骤,降低用户无助感;遮罩不关闭防误触退出。

✅ **验收要点**:
- 每个错误对话框包含四段:问题、原因、解决、按钮。
- 主按钮为最右且为最鼓励操作。
- 遮罩点击不关闭,需显式按钮或 Esc。
- 焦点默认落主按钮,Tab 在对话框内循环不跳出。
- 不展示技术堆栈/错误代码裸露(未知错误给编号 + [复制错误信息])。

## 5.8 屏幕八 · 不支持图片对话框 Unsupported Image Dialog

**目的 / 用户目标**:诚实告知哪些格式无法处理,让用户决定"跳过继续"还是"取消去找原文件"。

**形态**:
- 批量场景(扫描后发现不支持格式)→ 扫描结果页用 InfoBar 汇总"检测到 N 个暂不支持的文件"。

**布局**:

```
┌─ [⚠ 黄]  以下图片无法转换 ──────────────┐
│  本工具支持:JPEG / PNG / WebP / GIF /    │
│  BMP / TIFF / HEIC。                     │
│  以下格式暂不支持:                       │
│   · PSD 设计源文件 ×2                    │
│      截图_终稿.psd、banner.psd           │
```

**交互**:
- [继续处理(跳过)] → 跳过这些文件处理其余,跳过数计入结果。

**键盘**:Enter 继续处理;Esc 取消;Tab 遍历。

**设计原因**:支持格式与不支持格式同框对照,让用户自行判断;复制文件名降低"回去找原文件"的成本。

✅ **验收要点**:
- 对话框同时显示"支持格式"与"不支持格式"两段。
- [继续处理(跳过)]不中断主流程,跳过数计入结果。
- 勾选"以后自动跳过"后记忆,设置中可恢复。
- [复制文件名列表]复制成功有 Toast 反馈。

# 6. 组件规格

> 本章覆盖全部组件。每个组件统一含:作用、使用场景、视觉层级、状态、交互规则、禁用/加载/错误、提示方式、可访问性、响应行为、验收要点。所有控件支持完整键盘操作与可见焦点环。

## 6.1 按钮系统

**作用 / 场景**:触发操作或提交命令的主交互元素。每屏有且只有一个 Primary 主按钮承载唯一主行动。

**类型与视觉层级**:

| 类型                 | 外观                         | 用途                                             |
| -------------------- | ---------------------------- | ------------------------------------------------ |
| Primary 主按钮       | 强调色实底 + 白字            | 每屏唯一主行动(选择文件夹/开始处理/打开输出目录) |
| Secondary 次按钮     | 白底 + 强调色或中性 1px 描边 | 次要操作(取消/导出日志)                          |
| Subtle 微妙按钮      | 透明底,hover 浅灰            | 工具栏、低频操作(打开日志文件)                   |
| Destructive 危险按钮 | 红字描边 或 红底白字         | 取消处理、删除、重置设置                         |
| IconButton 图标按钮  | 40×40 方形,仅图标            | 标题栏控件、行内操作                             |
| SplitButton 分裂按钮 | Primary + 下拉箭头           | "选择文件夹"展开最近目录                         |

**尺寸(高度)**:大 48px(首页主 CTA 专用)/ 标准 40px / 紧凑 32px。最小点击目标 40×40。圆角 4px。横向内距:标准 16px,大号 24px。

**状态机**:

| 状态     | Primary                               | Secondary    | Subtle       | Destructive      | 过渡       |
| -------- | ------------------------------------- | ------------ | ------------ | ---------------- | ---------- |
| Normal   | 系统蓝实底                            | 白底蓝字描边 | 透明         | 红字描边         | —          |
| Hover    | 加深 `#005293`                        | 叠 `#F5F5F5` | 叠 `#F5F5F5` | 红底白字         | 100ms ease |
| Pressed  | 再加深 `#003F73`                      | 叠 `#EDEDED` | 叠 `#EDEDED` | 加深红 `#A11A0E` | 100ms ease |
| Focused  | Normal + 2px 强调色焦点环(offset 2px) | 同左         | 同左         | 同左             | 即时       |
| Disabled | 50% 透明 + `not-allowed` 光标         | 同左         | 同左         | 同左             | —          |
| Loading  | 文字→16px 环形进度(强调色),禁用点击   | 同左         | 同左         | 同左             | 即时       |

**交互/禁用/加载/错误**:后续步骤未达成时禁用主按钮(未扫描时[开始处理]禁用);异步操作 Loading 态禁用重复点击;按钮本身不承载错误,表单校验失败时提交按钮保持可点(点击触发字段级错误)。

**提示/无障碍**:IconButton 必有 `aria-label` + Tooltip;`<button>` 语义;Enter/Space 触发;焦点环可见。

**响应**:窗口 <960px 时操作栏按钮组保持横向但缩小内距;主按钮高度不降级(保证触摸目标)。

✅ **验收要点**:
- 每屏可见 Primary 主按钮至多 1 个。
- Hover/Pressed 颜色与状态机一致,过渡 100ms。
- 禁用态光标 `not-allowed`,Hover 无响应。
- 焦点环 2px + offset 2px,减少动画下仍可见。
- IconButton 100% 有 `aria-label` 且 Tooltip 可触发。
- 主按钮高度 ≥40px(首页 CTA 为 48px)。

## 6.2 开关 Toggle

**作用 / 场景**:二值状态切换(开/关),用于设置项。

**规格**:高 20px,轨道宽 40px,圆头;开 = 强调色轨道 + 白圆头居右;关 = 灰轨道 + 圆头居左。切换 150ms 滑动(减少动画可关)。

**状态**:Normal / Hover(轨道轻微加深)/ Focused(2px 焦点环)/ Disabled(50% 透明)。

**交互**:点击切换;Space/Enter 切换;Tab 可达。

**无障碍**:`role="switch"` + `aria-checked`;带可见文字标签(标题 + 描述)。

✅ **验收要点**:键盘 Space/Enter 可切换;切换有 150ms 滑动(减少动画下即时);带 `aria-checked`。

## 6.3 复选框 Checkbox

**作用 / 场景**:多选;支持三态(未选/已选/半选,半选用于"全选场景")。

**规格**:20×20 方框;勾选 = 强调色填充 + 白勾;未选 = 1px 边框空白;半选 = 强调色填充 + 横线。

**状态**:Normal / Hover / Focused / Disabled / 三态(未选/已选/半选)。

**交互**:点击切换;Space 切换;Tab 可达。

**无障碍**:`role="checkbox"` + `aria-checked`(true/false/mixed);label 显式关联。

✅ **验收要点**:支持三态;Space 可切换;label 与控件显式关联。

## 6.4 单选 Radio

**作用 / 场景**:组内单选(主题、输出位置、关闭行为等)。

**规格**:20×20 圆;选中 = 强调色实心内点;未选 = 1px 边框空白。

**状态**:Normal / Hover / Focused / Disabled / 选中/未选。

**交互**:点击选中;↑/↓ 或 ←/→ 在组内切换;Tab 进入组(聚焦选中项)。

**无障碍**:`role="radio"` + `aria-checked`;同组 `name` 统一。

✅ **验收要点**:同组内单选互斥;方向键在组内切换;Tab 进入组仅一次。

## 6.5 滑块 Slider

**作用 / 场景**:连续区间值(JPEG 质量 60–100、内存上限)。

**规格**:轨道高 4px,滑块 24px 圆;已填充部分强调色,未填充灰;旁显当前值。

**状态**:Normal / Hover(滑块放大)/ Focused(2px 焦点环)/ Disabled。

**交互**:拖动滑块;←/→ 微调(步进 1);Shift+←/→ 大步;Home/End 跳极值。

**无障碍**:`role="slider"` + `aria-valuemin/max/now`;带数值文本标签。

✅ **验收要点**:键盘 ←/→ 可调,Shift 大步,Home/End 跳极值;当前值实时显示。

## 6.6 数字步进 NumberBox

**作用 / 场景**:数值输入(并行数、最大宽高、日志保留天数)。

**规格**:高 40px,4px 圆角,1px 边框;右侧上下步进按钮;聚焦边框 2px 强调色。

**状态**:Normal / Focused / Disabled / 错误(超范围,红边 + 红字)。

**交互**:直接输入;上下按钮步进;Shift+步进 ×10;↑/↓ 微调。

**校验**:超出范围给红边 + 下方红字说明,不仅靠颜色。

## 6.8 文本框 TextBox

**作用 / 场景**:文本输入(子文件夹名、临时目录)。

✅ **验收要点**:折叠态显示摘要;`aria-expanded` 正确;Enter/Space 可切换。

## 6.14 线性进度 ProgressBar

**作用 / 场景**:确定/不确定进度(扫描、处理)。

**规格**:高 8px(处理页)/ 4px(紧凑);确定态强调色填充 + 底 `#E5E5E5`;不确定态强调色流动动画。

**规则**:进度条必须配文字说明当前在做什么(如"正在扫描… 已发现 230 张"),不裸用;完成态用对勾图标替换(单次绘制 300ms 仅一次)。

**无障碍**:`role="progressbar"` + `aria-valuenow/min/max`(确定态)。

✅ **验收要点**:进度条必配文字说明;不确定态有流动动画;完成用对勾替换;`aria-valuenow` 正确。

## 6.15 环形进度 ProgressRing

**作用 / 场景**:加载态、按钮 Loading。

**规格**:32–40px,强调色弧线旋转。

**无障碍**:配 `aria-label`(如"正在扫描");按钮内 Loading 用 `aria-busy`。

✅ **验收要点**:加载态环形进度 + 文字说明;按钮 Loading 禁用点击。

## 6.16 列表 / 图片列表 List

**作用 / 场景**:扫描结果详情、失败/跳过清单、最近文件夹。

**规格(扫描结果详情列表)**:行高 48px,hover `#F5F5F5`,分组分隔线;列 = 缩略图 40×40(可选)· 文件名(截断 Tooltip 全名)· 格式徽章 · 大小 · 状态徽章。

**规格(表格,日志/失败清单)**:等宽列,等宽字体 12px(日志),表头 sticky,斑马纹可选。

**交互**:可按格式/状态筛选(顶部徽章点击即筛选);行可点击展开详情。

✅ **验收要点**:行 hover 浅灰;长文件名截断 + Tooltip;表头 sticky;徽章可筛选。

## 6.17 设置行 SettingRow

**作用 / 场景**:设置页核心模式。

**规格**:左 = 标题(body-strong)+ 描述(caption 次色)+ 可选影响/推荐 Tooltip ⓘ;右 = 控件;下方细分隔线。

**交互**:鼠标悬停 ⓘ 显示影响说明 Tooltip;改动即时保存。

✅ **验收要点**:左标题+描述、右控件布局;ⓘ Tooltip 说明影响;改动即时保存。

## 6.18 徽章 Badge

**作用 / 场景**:标识格式、模式、状态(无需转换/将转换/演示)。

**规格**:小标签;强调色浅底 或 语义色;可选图标。

**变体**:`ok`(无需转换)、`convert`(将转换)、`warn`(点击查看)、`accent`(当前/演示)。

✅ **验收要点**:徽章颜色语义一致;可点击徽章(如"点击查看")有交互反馈。

## 6.19 步骤条 Stepper

**作用 / 场景**:主流程 4 步进度指示。

**规格**:水平四步;已完成 = 对勾 + 强调色;当前 = 强调色实心数字;未到达 = 灰;当前步骤下方可显示子进度。

**交互**:可点已完成步骤回退;不可点未到达步骤前进。

**无障碍**:`aria-current="step"`(当前步);各步 `aria-label`。

✅ **验收要点**:已完成显示对勾;未到达步骤不可点击;当前步 `aria-current`。

## 6.20 拖拽区 DropZone

**作用 / 场景**:首页核心入口,接受文件夹拖拽。

**规格**:2px 虚线强调边框,8px 圆角,浅底 `#FAFCFF`;中央文件夹图标 48px + 提示 + 主按钮;约占视口高度 40%。

**状态**:Normal / 拖拽悬停(边框实线强调色 + 背景 `#E5F1FB` + 文字"松开即可开始扫描")/ 错误(拖入非文件夹,红字提示)。

**交互**:拖入文件夹自动扫描;拖入文件提示"请拖入文件夹";拖入多文件夹提示"一次只能处理一个文件夹"。

**无障碍**:`tabindex="0"` + `role="button"` + `aria-label`;聚焦时 Enter = 选择文件夹。

✅ **验收要点**:拖拽悬停态边框/背景/文字三者同步变化;拖入文件/多文件夹有对应提示;聚焦时 Enter 触发选择。

## 6.21 模态对话框 ContentDialog

**作用 / 场景**:错误、确认、不支持格式(详见 §5.7、§8)。

**规格**:居中,8px 圆角,宽 448–548px;遮罩 `rgba(0,0,0,0.3)`,遮罩点击**不关闭**;标题区(图标 + 标题)→ 内容区 → 按钮区(右下,主按钮最右)。

**交互**:焦点默认主按钮;Tab 在对话框内循环;出现/消失 200ms 缩放+淡入(减少动画可关);Esc 关闭/取消。

✅ **验收要点**:遮罩点击不关闭;焦点默认主按钮;Tab 内循环不跳出;Esc 关闭。

## 6.22 Flyout 浮层

**作用 / 场景**:快速设置、最近目录下拉、兼容模式切换。

**规格**:锚定触发控件,小箭头指向,8px 圆角,Flyout 阴影。

**交互**:点击外部或 Esc 关闭;焦点进入浮层,Tab 在浮层内循环。

✅ **验收要点**:锚定触发控件;点击外部/Esc 关闭;焦点不跳出浮层。

## 6.23 Tooltip

**作用 / 场景**:悬停/聚焦补充说明(长文件名、设置项影响)。

**规格**:悬停/聚焦 500ms 后出现;黑底白字(Light)/ 白底黑字(Dark);12px,最多两行;4s 自动消失。

**无障碍**:纯装饰性 Tooltip 不依赖它传递关键信息(关键信息要可见文字);聚焦时也出现。

✅ **验收要点**:延迟 500ms 出现;聚焦触发;4s 消失;关键信息不唯一依赖 Tooltip。

## 6.24 Toast

**作用 / 场景**:非模态成功/信息提示(已导出日志到桌面、配置文件无效)。

**规格**:右下角;自动 4–7s 消失;可手动×;200ms 右下滑入/淡出(减少动画可关)。

**无障碍**:`role="status"` + `aria-live="polite"`。

✅ **验收要点**:右下角;4–7s 自动消失;可手动关;`aria-live` 播报。

## 6.25 菜单浮层 / 溢出菜单

**作用 / 场景**:标题栏 `⋯` 展开的设置/日志/关于入口;演示入口。

**规格**:纵向列表;每项 = 图标 + 文字 + 快捷键提示;8px 圆角,Flyout 阴影。

**交互**:点击项目执行并关闭;点击外部/Esc 关闭;↑/↓ 导航,Enter 选中。

**无障碍**:`role="menu"`,项 `role="menuitem"`。

✅ **验收要点**:每项有图标 + 文字 + 快捷键;↑/↓ 导航、Enter 选中、Esc 关闭。

## 6.26 标题栏 TitleBar

**作用 / 场景**:窗口顶部常驻(详见 §3.1)。

**规格**:高 40px;左 Logo + 应用名;中拖拽区;右 兼容模式徽章 + `⋯` + 系统控件(最小化/最大化/关闭)。

**交互**:双击拖拽区 = 最大化/还原;拖动拖拽区 = 移动窗口。

✅ **验收要点**:高 40px;双击最大化;拖动移动窗口;三端外观一致(应用自绘)。

## 6.27 状态栏 StatusBar

**作用 / 场景**:窗口底部常驻,环境信息。

**规格**:三段式——左"就绪/处理中/扫描中"(带状态点)· 中"兼容模式 · 输出位置"· 右"离线 · 版本号";caption 12px。

**状态点颜色**:就绪 = 灰/绿、处理中 = 强调色、扫描中 = 强调色脉动、错误 = 红。

**无障碍**:`role="status"` + `aria-live`(状态变化播报)。

✅ **验收要点**:三段式常驻;"离线"标识始终可见;状态点随状态变化;状态变化 `aria-live` 播报。

## 6.28 空状态 EmptyState

**作用 / 场景**:无数据时的引导(无最近文件夹、扫描 0 张、搜索无果)。

**模板**:大图标 64px(三级文字色)+ 一句话标题 + 可选一句描述 + 可选主按钮。

**实例**:
- 首页无最近:"还没有最近处理过的文件夹" + "把文件夹拖到上方区域,或点击选择文件夹"。
- 扫描 0 张:"这个文件夹里没有可处理的照片" + [重新选择文件夹]。
- 设置搜索无果:"没有匹配的设置项"。

✅ **验收要点**:空状态有大图标 + 标题;提供明确下一步操作(按钮或引导文字)。

## 6.29 操作栏 ActionBar

**作用 / 场景**:页面底部固定操作区(扫描结果、处理中、完成)。

**规格**:sticky 底部;左 = 摘要信息(如"共 230 张,预计输出约 48 MB");右 = 按钮组(主按钮最右);1px 顶部分隔线。

**响应**:窄屏下按钮组保持可见,主按钮不降级高度。

✅ **验收要点**:操作栏 sticky 始终可见;主按钮在最右;窄屏下主按钮高度不降级。

# 7. 表单规范

> 设置页是本应用唯一的表单场景。所有表单控件遵循 §6 组件规格;本章补充输入、校验、默认值、错误提示等表单层规则。

## 7.1 输入规则

| 控件                   | 输入规则                                          |
| ---------------------- | ------------------------------------------------- |
| 文本框(子文件夹名)     | 仅允许文件系统合法字符;禁用 `\ / : * ? " < >      | ` |
| 文本框(临时目录)       | 接受完整路径;Windows 反斜杠 `\`、Linux 正斜杠 `/` |
| 数字步进(并行数)       | 整数,范围 1–CPU 核心数;ARM/LoongArch 上限 4       |
| 数字步进(最大宽高)     | 整数,范围 1–8192                                  |
| 数字步进(日志保留天数) | 整数,范围 1–365                                   |
| 滑块(JPEG 质量)        | 整数,范围 60–100                                  |
| 浏览框(输出目录)       | 必须为已存在且可写目录                            |

## 7.2 校验规则

- **触发时机**:失焦时校验 + 改动后即时重校(错误态下用户修改即清除错误);提交(应用配置)时强制校验。
- **错误反馈**:红边 + 下方红字说明 + 图标,**不仅靠颜色**。
- **非法字符**:输入时直接拦截(不接受非法字符输入)或失焦时报错——采用失焦报错 + 红字提示"不能包含 \ / : * ? " < > |"。

## 7.3 默认值

见 §5.6 设置页表格"默认"列。关键默认:`compat` 子文件夹、JPEG 质量 90、最大宽高 4096px、并行数随架构、日志保留 30 天。

## 7.4 占位提示

- 文本框无值时显示占位(次色文字),如子文件夹名框占位 `compat`。
- 占位不可作 label 替代,所有控件必须有显式标题(label)。

## 7.5 错误提示

| 场景                 | 错误文案                              |
| -------------------- | ------------------------------------- |
| 子文件夹名含非法字符 | 子文件夹名不能包含 \ / : * ? " < > \| |
| 输出目录不可写       | 这个目录无法写入,请选择其他位置       |
| 数字超范围           | 请输入 1 到 N 之间的数字              |
| 导入配置格式错误     | 配置文件无效,未导入(Toast)            |

## 7.6 必填 / 可选

- 本应用设置项**无强制必填**(均有默认值);输出"指定目录"模式下,目录为空时浏览框给提示。
- 所有设置项有默认值,空值等于默认值。

## 7.7 快捷键

| 快捷键          | 功能                    |
| --------------- | ----------------------- |
| Ctrl+F          | 搜索设置项              |
| Tab / Shift+Tab | 焦点前后移动            |
| Enter           | 激活当前控件(按钮/单选) |
| Space           | 切换开关/复选框         |
| Esc             | 关闭设置页              |
| Ctrl+Z          | 撤销上一步设置改动      |

## 7.8 复制粘贴

- 文本框/浏览框支持 Ctrl+C/V;粘贴路径自动规范化(去首尾空格)。
- 粘贴非法字符时按 §7.2 处理(失焦报错)。

## 7.9 拖拽行为

- 设置页**不接受**拖拽输入(拖拽是主流程入口,设置页不响应)。
- 拖拽文件夹只在首页拖拽区生效。

## 7.10 批量输入规则

- 本应用无批量输入场景(单目录处理)。
- 批量配置通过"导入配置"实现(导入一份配置文件应用到本机)。

✅ **验收要点**:
- 非法字符输入有红边 + 文字提示。
- 所有控件有显式标题,不依赖占位作 label。
- 设置改动即时保存 + 可 Ctrl+Z 撤销。
- 拖拽在设置页无响应。

# 8. 弹窗规范

> 所有模态弹窗遵循统一契约。每个弹窗必含**问题 / 原因 / 解决 / 按钮**四段;主按钮 = 最鼓励操作;Esc = 取消/关闭;遮罩点击**不关闭**;焦点默认主按钮。

## 8.10 磁盘空间不足

| 项       | 内容                                                                                                          |

| 触发     | 输出磁盘剩余空间不足(处理前预估或处理中写满)                                                                  |
| 目的     | 告知空间不足,给解决路径                                                                                       |
| 内容     | 问题:磁盘空间不足,无法保存结果 / 原因:输出磁盘剩余不够 / 解决:①清理磁盘 ②改到其他磁盘 ③降低 JPEG 质量减小体积 |
| 按钮     | [打开设置](主) [关闭]                                                                                         |
| 默认焦点 | [打开设置]                                                                                                    |

## 8.11 未知错误

| 项       | 内容                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------- |
| 触发     | 程序内部异常,无法归类                                                                             |
| 目的     | 诚实告知 + 引导反馈,不裸露技术堆栈                                                                |
| 内容     | 问题:出现了一个意外问题 / 原因:程序内部异常(附错误代码)/ 解决:已记录到日志,请把日志反馈给技术支持 |
| 按钮     | [复制错误信息] [打开日志](主) [关闭]                                                              |
| 默认焦点 | [打开日志]                                                                                        |
| 注意     | 给编号(如 ERR-0x...)便于排查,不裸露堆栈                                                           |

## 8.12 用户取消（完成态,非错误）

| 项       | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 触发     | 经 §8.6 确认取消后,跳完成页                                  |
| 目的     | 告知取消结果,已处理部分可用                                  |
| 形态     | 完成页"已取消"标记态(非弹窗),内容:已处理的文件保留在输出目录 |
| 按钮     | [打开部分输出](主) [处理另一个] [关闭]                       |
| 默认焦点 | [打开部分输出]                                               |

✅ **验收要点**:
- 所有弹窗含四段结构(问题/原因/解决/按钮)。
- 遮罩点击不关闭;Esc 取消;回车触发默认焦点按钮。

- 未知错误给编号 + 复制,不裸露堆栈。
- 处理中关闭必弹 §8.5 中断确认。

# 9. 消息通知规范

> 通知分三层:页内 InfoBar(需注意不阻断)、右下角 Toast(瞬时反馈)、状态栏(环境信息)。三者职责不重叠。

## 9.1 Toast

| 项       | 规则                                                |
| -------- | --------------------------------------------------- |
| 位置     | 窗口右下角                                          |
| 用途     | 成功/信息瞬时反馈(已导出日志、配置已导入、复制成功) |
| 自动关闭 | 4–7s(成功 4s,信息 7s)                               |
| 手动关闭 | 可点 ×                                              |
| 动画     | 200ms 右下滑入/淡出(减少动画可关)                   |
| 非模态   | 不阻断主流程                                        |
| 无障碍   | `role="status"` + `aria-live="polite"`              |

## 9.2 状态栏提示

| 项     | 规则                                                                   |
| ------ | ---------------------------------------------------------------------- |
| 位置   | 窗口底部常驻                                                           |
| 三段   | 左:就绪/处理中/扫描中(带状态点)· 中:兼容模式·输出位置 · 右:离线·版本号 |
| 用途   | 环境信息与当前状态                                                     |
| 无障碍 | `role="status"` + `aria-live`(状态变化播报)                            |

## 9.3 通知栏（InfoBar）

| 项     | 规则                                                 |
| ------ | ---------------------------------------------------- |
| 位置   | 页内顶部嵌入(扫描结果、处理中)                       |
| 用途   | 需用户注意但不阻断的警告/提示(检测到 HEIC、失败较多) |
| 四色   | Info/Warning/Error/Success,均配图标                  |
| 关闭   | 可点 × 关闭(部分关键警告不可关)                      |
| 无障碍 | `role="status"`/`alert`(错误级) + `aria-live`        |

## 9.4 处理完成提示

| 渠道         | 规则                        |
| ------------ | --------------------------- |
| 完成页       | 绿色对勾 + 成功统计(主反馈) |
| 系统托盘通知 | 窗口非聚焦时发送(可设置关)  |
| 任务栏闪烁   | 窗口非聚焦时闪烁(可设置关)  |
| 完成提示音   | 播放一声(可设置关)          |

## 9.5 失败提示

| 渠道   | 规则                                     |
| ------ | ---------------------------------------- |
| 处理中 | 失败统计卡高亮红 + 可点查看清单          |
| 超阈值 | 顶部黄色 InfoBar"失败较多,建议查看日志"  |
| 完成页 | 失败 >0 时显示[查看失败列表]按钮         |
| 日志   | 每个失败项记日志(时间戳 + 文件名 + 原因) |

## 9.6 自动关闭规则

| 通知类型   | 自动关闭                                |
| ---------- | --------------------------------------- |
| Toast 成功 | 4s                                      |
| Toast 信息 | 7s                                      |
| Toast 错误 | 不自动关闭(需手动 × 或显式操作)         |
| InfoBar    | 可手动关;关键警告(如失败超阈值)不自动关 |
| 状态栏     | 常驻不关                                |

## 9.7 优先级规则

同时多个通知时,叠加显示顺序(自上而下/自右而左):

1. Error 错误(最高)
2. Warning 警告
3. Info 信息
4. Success 成功

错误永远最先被看到。

## 9.8 连续通知规则

- 同类连续通知**合并**:扫描发现多张 HEIC 不逐张 Toast,合并为一条 InfoBar"检测到 8 张 HEIC"。
- 处理中失败不逐个 Toast,汇总为失败计数 + 日志。
- Toast 叠加上限 3 条,超出则最早的淡出。

✅ **验收要点**:
- Toast 成功 4s、信息 7s、错误不自动关。
- 错误通知优先级最高,最先可见。
- 同类通知合并,不刷屏。
- 窗口非聚焦完成时触发托盘通知 + 任务栏闪烁(除非设置关)。
- 所有动态通知有 `aria-live` 播报。

# 10. 图片处理过程体验

> 本章描述从扫描到完成的完整处理体验,含状态机、进度计算、剩余时间估算、失败统计、性能自适应。

## 10.1 处理状态机

```
扫描中 ──完成──► 统计完成(扫描结果页)
                    │
               [开始处理]
                    ▼
                处理中 ◄──继续──► 已暂停
                  │                   │
              [取消确认]           [暂停]
                  │                   │
                  ▼                   ▼
            完成(取消态)         (可恢复)
                  │
              全部完成
                  │
                  ▼
            完成(成功态)
```

## 10.2 扫描

- **触发**:选定/拖入文件夹后自动开始,无需点确认。
- **过程**:递归遍历目录,识别支持格式(JPEG/PNG/WebP/GIF/BMP/TIFF/HEIC),统计数量、体积、格式分布,检测损坏与不支持格式。
- **反馈**:环形进度 + "正在扫描 文件夹名… 已发现 N 张"(实时刷新计数)。
- **完成**:进入扫描结果页,显示统计卡、格式分布、警告 InfoBar。

## 10.3 统计

| 统计项       | 计算依据                           |
| ------------ | ---------------------------------- |
| 总图片数     | 支持格式文件数                     |
| 预计输出数量 | = 总图片数 - 损坏数(损坏跳过)      |
| 预计输出大小 | 按历史压缩比预估(或采样若干张估算) |
| 预计节省     | 原始体积 - 预计输出大小            |
| 格式分布     | 各格式数量 + 横条占比              |

- 预估为**预估值**,完成后以实际为准;预估必须显示(确定性原则)。

## 10.4 处理中

- **进度**:大百分比 + 8px 进度条 + "已处理 N / 总数"。
- **当前文件**:缩略图 + 文件名 + 当前操作徽章(如"转换 HEIC → JPEG")。
- **实时统计**:已用时间、预计剩余、速度(张/秒)、已处理、失败、跳过。
- **日志**:默认折叠一行,展开滚动列表。

## 10.5 暂停 / 继续

- **暂停**:点[暂停] / 按 Space;进度条变灰,计数暂停,按钮变[继续],状态栏"已暂停"。
- **继续**:点[继续] / 按 Space;恢复处理,已用时间继续累计(暂停期间不计)。

## 10.6 取消

- 点[取消] / 按 Esc → §8.6 取消确认 → 确认后停止,跳完成页(取消态),已处理部分保留。

## 10.7 完成 / 失败

| 结果               | 表现                                                    |
| ------------------ | ------------------------------------------------------- |
| 全部成功           | 绿色对勾 + 成功统计 + [打开输出目录]                    |
| 部分失败           | 成功统计 + 失败/跳过计数(可点查看)+ [打开输出目录]      |
| 整体失败(磁盘满等) | 红色"处理未完成" + 已处理部分 + [重试] + [打开部分输出] |
| 用户取消           | "已取消"标记 + 已处理部分 + [打开部分输出]              |

## 10.8 恢复处理

- 本期**不支持**中断后断点续传(程序异常退出后从头开始)。
- 已输出的文件保留在输出目录(不回滚)。
- 重复处理时,因默认"不覆盖",已存在文件跳过或加序号。

## 10.9 日志更新

| 项     | 规则                                          |
| ------ | --------------------------------------------- |
| 级别   | 常规 / 详细(设置可选)                         |
| 内容   | 时间戳 + 文件名 + 操作 + 状态(✓/✕/跳过)       |
| 频率   | 每个文件处理完成写一条;失败/跳过额外记原因    |
| 展示   | 处理中可折叠面板实时滚动;等宽 12px,状态色     |
| 持久化 | 写入日志文件,保留 30 天(可设),超期清理        |
| 导出   | 完成[导出日志] / Ctrl+E / Ctrl+L 打开日志文件 |

## 10.10 进度更新

- **计算**:已处理数 / 总数 × 100%。
- **刷新频率**:每处理完一张更新一次(避免过频闪烁)。
- **不确定态**:扫描初期或"准备中"显示不确定流动进度条。
- **数字**:百分比与计数使用等宽数字,平滑跟进(≤200ms),减少动画可关。

## 10.11 剩余时间估算

- **算法**:滑动平均——取最近 N 张(如 20 张)的处理速度,剩余时间 = 剩余张数 / 平均速度。
- **预热**:前 5 张不显示预计剩余(显示 `--:--`),避免初始估算不准。
- **跳过**:暂停期间不计入速度;恢复后重新采样。
- **更新**:每 5 张刷新一次,避免数字跳动。

## 10.12 失败统计

- 失败计数实时累加;失败统计卡 >0 变红可点查看清单。
- 跳过(损坏/不支持)单独计数,灰色。
- 失败超阈值(>5% 或 >20 张)→ 顶部黄色 InfoBar 建议。
- 每个失败项记日志:时间戳 + 文件名 + 错误原因。

## 10.13 性能自适应

| 设置项       | x86_64 / 通用 | ARM(鲲鹏/飞腾)/ LoongArch(龙芯) |
| ------------ | ------------- | ------------------------------- |
| 并行处理数   | CPU 核心数    | min(核心数, 4),留 1 核给系统    |
| 内存上限     | 系统内存 75%  | 系统内存 50%                    |
| 大图采样缩放 | 开(可关)      | **强制开,不可关**(防内存溢出)   |

- 程序自动检测架构,**不暴露架构选择给用户**。
- 用户手动调高并行数时给温和提示"当前架构性能有限,过高可能导致卡顿"。

✅ **验收要点**:
- 扫描发现计数实时刷新。
- 进度 = 已处理/总数,百分比与进度条同步。
- 预计剩余前 5 张显示 `--:--`,之后基于滑动平均。
- 暂停期间已用时间不累计、速度不采样。
- 单文件失败不中断主流程,记日志 + 失败计数。
- 架构自适应默认值正确,大图采样在 ARM/LoongArch 不可关。

# 11. 可访问性（Accessibility）

> 本产品用户含大量中老年、视力受限、操作不熟练群体,无障碍是**一等需求**而非附加项。

## 11.1 九维度要求矩阵

| 维度         | 要求                                                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 键盘完整操作 | 100% 操作有键盘等价;逻辑 Tab 顺序(左上→右下,符合阅读顺序);可见焦点环 2px 强调色(offset 2px),不依赖颜色,减少动画下不消失                        |
| 屏幕阅读器   | 全语义角色(role/aria-label);进度条 `role="progressbar"` + `aria-valuenow`;统计卡 `aria-label="总图片数 230"`;图标按钮必有 `aria-label`+Tooltip |
| 高对比度     | 跟随系统高对比度主题(Windows 高对比度 / Linux GTK 高对比度),控件边框加粗,背景纯化                                                              |
| 大字号       | 标准/大/超大 三档(×1.25/×1.5),布局自适应不溢出不裁切                                                                                           |
| 焦点显示     | 2px 强调色焦点环 + 2px offset;模态内 Tab 循环;关闭浮层后焦点回触发控件                                                                         |
| 颜色区分     | 状态编码不依赖颜色,颜色 + 图标 + 文字三重编码                                                                                                  |
| 色盲兼容     | 成功/失败/警告同时用颜色 + 图标 + 文字;红绿不并用作唯一区分                                                                                    |
| 减少动画     | 跟随系统"减少动画",开启后过渡 ≤50ms 或即时;焦点环不消失                                                                                        |
| 点击目标     | 桌面 ≥40×40;主要按钮放大到 48;点击距离充足                                                                                                     |

## 11.2 对比度（WCAG AA）

| 元素                         | 要求    |
| ---------------------------- | ------- |
| 正文(14px 及以下)            | ≥ 4.5:1 |
| 大字(18px+ 或 14px 600 字重) | ≥ 3:1   |
| 焦点环 vs 背景               | ≥ 3:1   |

## 11.3 语义角色与 ARIA 用法

| 组件     | 角色/属性                                                 |
| -------- | --------------------------------------------------------- |
| 进度条   | `role="progressbar"` + `aria-valuenow/min/max`            |
| 环形加载 | `aria-label` 或按钮内 `aria-busy="true"`                  |
| 统计卡   | `aria-label` 播报完整(如"总图片数 230")                   |
| 图标按钮 | `aria-label` + Tooltip                                    |
| 开关     | `role="switch"` + `aria-checked`                          |
| 复选框   | `role="checkbox"` + `aria-checked`(true/false/mixed)      |
| 单选     | `role="radio"` + `aria-checked`                           |
| 滑块     | `role="slider"` + `aria-valuemin/max/now`                 |
| 下拉     | `role="combobox"` + `aria-expanded`                       |
| 对话框   | `role="dialog"` + `aria-modal="true"` + `aria-labelledby` |
| 步骤条   | `aria-current="step"`(当前步)                             |
| 菜单     | `role="menu"`,项 `role="menuitem"`                        |

## 11.4 aria-live 播报清单

动态变化的内容必须用 `aria-live` 即时播报:

| 场景              | aria-live                                             |
| ----------------- | ----------------------------------------------------- |
| 进度百分比变化    | `aria-live="polite"`(或通过 `aria-valuenow` 自动播报) |
| Toast 出现        | `role="status"` + `aria-live="polite"`                |
| 错误 InfoBar 出现 | `role="alert"`                                        |
| 扫描发现计数刷新  | `aria-live="polite"`                                  |
| 状态栏状态变化    | `role="status"` + `aria-live="polite"`                |

## 11.5 键盘可达性细则

- 所有可操作元素 Tab 可达;逻辑顺序 = 视觉阅读顺序(左上→右下)。
- 模态对话框:打开后焦点进主按钮,Tab 在弹窗内循环,不跳到背景;关闭后焦点回触发控件。
- 拖拽区:`tabindex="0"` + `role="button"`,聚焦时 Enter = 选择文件夹(键盘可达的拖拽替代)。
- 快捷键全部有等价鼠标/触摸操作,不强制记忆。

## 11.6 认知负荷

- 一屏一主行动;术语去技术化;危险操作二次确认;可撤销(Ctrl+Z 撤销设置改动)。
- 错误提示给出可操作解决步骤,不只报错。

✅ **验收要点**:
- 100% 操作键盘可达,Tab 顺序符合阅读顺序。
- 所有状态编码具备颜色+图标+文字三重表征。
- 正文对比度 ≥4.5:1,大字 ≥3:1。
- 焦点环在所有状态(含减少动画)下可见。
- 动态变化内容有 `aria-live` 播报。
- 所有图标按钮有 `aria-label`。
- 大字号 ×1.25/×1.5 下布局不溢出不裁切。
- 点击目标 ≥40×40,主要按钮 48。

# 12. 设计规范（Design Tokens）

> 本章只描述设计规范,**不含任何代码、不含层叠样式表变量名**。所有色值、字号、间距均为规格数据,供视觉还原与走查使用。

## 12.1 颜色语义

### 12.1.1 强调色（Accent）

| 强调色 禁用     | `#8AB8E8`  | `#3A5C7A` | 与文字色 40% 混合                  |

| 前景文字 三级/禁用 | `#8A8A8A`  | 占位、禁用态文字                          |
| 边框 细            | `#E5E5E5`  | 卡片、输入框常规边框                      |
| 边框 强            | `#D1D1D1`  | 拖拽区虚线、强调边框                      |
| 分隔线             | `#EDEDED`  | 列表行分隔、设置行分隔                    |

### 12.1.3 中性色（Dark 主题要点）

| 语义             | Dark 色值             |
| ---------------- | --------------------- |
| 窗口背景         | `#202020`             |
| 卡片/面板表面    | `#2B2B2B`             |
| 前景文字 主 / 次 | `#FFFFFF` / `#C5C5C5` |
| 边框             | `#3F3F3F`             |

> 主题切换**跟随系统**为默认;强调色与语义色按上述 Light/Dark 列对应。

### 12.1.4 语义色（状态编码）

> **硬约束**:所有状态色必须"颜色 + 图标 + 文字"**三重编码**,绝不只靠颜色区分(色盲友好)。

| 语义         | 主色(Light) | 浅底      | 图标   |
| ------------ | ----------- | --------- | ------ |
| 成功 Success | `#107C10`   | `#DFF6DD` | ✓ 圆勾 |
| 警告 Warning | `#9D5D00`   | `#FFF4CE` | ⚠ 三角 |
| 错误 Error   | `#C42B1C`   | `#FDE7E9` | ✕ 圆叉 |
| 信息 Info    | `#0067C0`   | `#E5F1FB` | i 圆点 |

## 12.2 字体层级（字体栈）

**不引入网络字体**(离线原则),全部使用各平台预装字体,按平台回退。

| 用途                       | 字体栈(按命中优先级)                                                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| UI 西文                    | "Segoe UI Variable Text" → "Segoe UI"(Windows)→ "Cantarell" → "Inter"(Linux)→ system-ui → sans-serif                                 |
| UI 中文                    | "Microsoft YaHei UI" → "Microsoft YaHei"(Windows)→ "Source Han Sans SC" → "Noto Sans CJK SC"(Linux/信创)→ "PingFang SC" → sans-serif |
| 显示标题                   | "Segoe UI Variable Display" → "Source Han Sans SC" → "Microsoft YaHei UI" → sans-serif                                               |
| 等宽(日志、路径、数字对齐) | "Cascadia Code" → "Consolas"(Windows)→ "JetBrains Mono" → "DejaVu Sans Mono"(Linux)→ ui-monospace → monospace                        |

- **信创注意**:Linux 回退栈须含思源黑体/Noto Sans CJK SC;文案避免生僻字(部分老国产系统缺字)。

## 12.3 字号阶梯

| 令牌        | 字号    | 行高 | 字重 | 用途                        |
| ----------- | ------- | ---- | ---- | --------------------------- |
| caption     | 12px    | 1.4  | 400  | 状态栏、辅助说明、时间戳    |
| body        | 14px    | 1.5  | 400  | 正文、控件文字(Fluent 默认) |
| body-strong | 14px    | 1.5  | 600  | 强调文字、按钮              |
| subtitle    | 20px    | 1.3  | 600  | 区块标题                    |
| title       | 28px    | 1.25 | 600  | 页面主标题                  |
| large-title | 40px    | 1.2  | 600  | 首页大字(慎用)              |
| display-num | 48–56px | 1.0  | 600  | 统计大数字(必须等宽对齐)    |

- **字重只用 Regular 400 与 Semibold 600**,不用 Bold 700(Fluent 体系以 Semibold 表强调,过粗在小字号下糊)。
- **大字号辅助**:开启时整套阶梯 ×1.25(大)/ ×1.5(超大)。
- 统计数字必须使用等宽数字对齐(`tabular-nums`),避免数字跳动。

## 12.4 间距体系

基于 **4px 基础栅格**。所有间距取 4 的倍数,**禁止 5 / 7 / 10 等游离值**。

| 令牌 | 值   | 典型用途                     |
| ---- | ---- | ---------------------------- |
| xxs  | 4px  | 图标与文字间距、紧凑控件内距 |
| xs   | 8px  | 控件内 padding、列表行内间距 |
| s    | 12px | 输入框内距、按钮横向内距     |
| m    | 16px | 卡片内距、控件组间距         |
| l    | 24px | 区块内间距、页面边距(小窗)   |
| xl   | 32px | 区块间距、页面边距(大窗)     |
| xxl  | 48px | 首页大区块间距               |

- **规则**:相邻元素间距取上一级令牌;卡片之间 16,区块之间 24–32。

## 12.5 圆角规范

| 元素                          | 圆角    |
| ----------------------------- | ------- |
| 按钮 / 输入框 / 小控件        | 4px     |
| 卡片 / 对话框 / 面板 / 拖拽区 | 8px     |
| 状态点 / 头像                 | 50%(圆) |

## 12.6 阴影规范（Elevation）

| 层级            | 用途              | 阴影值                        |
| --------------- | ----------------- | ----------------------------- |
| Rest            | 卡片静置          | `0 2px 4px rgba(0,0,0,0.06)`  |
| Hover           | 可悬停列表项/卡片 | `0 2px 8px rgba(0,0,0,0.08)`  |
| Flyout / Dialog | 浮层 / 对话框     | `0 8px 16px rgba(0,0,0,0.14)` |
| Tooltip         | 提示              | `0 4px 8px rgba(0,0,0,0.12)`  |

## 12.7 图标规范

- **风格**:Fluent System Icons,线性 outline,统一 2px 描边,圆角端点,几何对称。
- **尺寸**:默认 24px;行内辅助 16px。
- **着色**:默认继承当前文字色;强调图标用强调色;状态图标用对应语义色;装饰图标用次级文字色。
- **禁用**:表情符号作功能图标、彩色立体拟物、手绘风、游戏化图标。
- **无障碍**:所有图标按钮必须有 `aria-label` + Tooltip;纯图标行必须配文字标签。
- **核心图标集**:文件夹、文件夹-打开、扫描/雷达、开始/播放、暂停、取消/×、完成/✓、警告/⚠、错误/✕、信息/i、设置/齿轮、日志/文档、输出目录、图片/相框、刷新、搜索、拖拽手柄、帮助/问号。

## 12.8 状态颜色（与语义色一致）

状态颜色即 §12.1.4 语义色。再次强调:**颜色 + 图标 + 文字三重编码**,红绿不并用作唯一区分,成功/失败/警告同时具备三种编码。

## 12.9 组件密度

- **标准密度**:默认。
- **大字号**:`标准 / 大 / 超大` 三档,大 = ×1.25,超大 = ×1.5,布局自适应不溢出、不裁切。
- **最小触摸目标**:主要按钮放大到 48px 高;所有可点击元素 ≥ 40 × 40。

## 12.10 动效规范（克制原则）

- 动画仅用于**反馈状态变化**,绝不作装饰。时长 100–200ms,缓动 `ease` / `ease-out`。
- "减少动画"开启时:过渡 ≤ 50ms 或即时。
- **禁用动效**:背景渐变流动、粒子、3D 翻转、常驻脉冲、视差滚动、开机炫酷动画。

✅ **验收要点**:
- 强调色默认为系统蓝 `#0067C0`,界面无品牌橙红作默认色。
- 所有间距为 4 的倍数,无 5/7/10 游离值。
- 字重仅出现 400 与 600,无 700。
- 所有状态编码具备"颜色+图标+文字"三重表征。
- 界面无表情符号作功能图标。
- 大字号 ×1.25 / ×1.5 下布局不溢出、不裁切。
- 界面无网络字体加载。

# 13. 文案规范

> 面向普通办公人员(大量中老年、计算机水平一般)。整体语气:**诚实、克制、去技术化、可操作**。

## 13.1 整体语气

- **诚实**:不夸大能力,不承诺"100% 成功";明确告知不支持、损坏、失败。
- **克制**:成功时不欢呼,用"处理完成"而非"太棒了";错误时不制造恐慌。
- **去技术化**:用通俗说法替代专业术语(见 §13.7 术语表)。
- **可操作**:错误永远给解决路径(问题/原因/解决/按钮),不只报错。
- **第二人称**:对用户用"您"(如"您的照片"),不用"你"或"我"。

## 13.2 按钮命名规范

- **动词开头**,明确动作与对象:[选择文件夹]、[开始处理]、[打开输出目录]、[导出日志]、[重新选择]、[继续处理]。
- **主按钮**:积极、鼓励、明确下一步([开始处理]、[打开输出目录])。
- **危险按钮**:明确后果([确定取消]、[重置所有设置]),不用模糊的[确认]。
- **取消类**:用[取消]或[关闭],不用[返回](易与导航混淆)。
- **长度**:2–6 字为宜,不超过 8 字。

## 13.3 提示文字规范

- **引导**:告诉用户"能做什么",而非"不能做什么"。用"把文件夹拖到这里",不用"请勿拖入文件"。
- **进度**:说明当前在做什么 + 已完成量,"正在扫描… 已发现 230 张",不裸用进度条。
- **状态**:简明描述,"就绪 / 扫描中 / 处理中 / 已暂停",不用"正在处理,请稍候..."。

## 13.4 错误提示规范

四段结构(问题 / 原因 / 解决 / 按钮):
- **问题**:一句话说清发生了什么,"无法读取这个文件夹"。
- **原因**:列出可能原因,用通俗话,"文件夹已被移动或删除"、"系统权限不足"。
- **解决**:编号步骤,可执行,"① 确认文件夹存在 ② 重新选择"。
- **按钮**:最鼓励的操作为主按钮,[重新选择] 而非[确定]。
- **禁令**:不裸露技术堆栈、不显示原始错误码(给编号如 ERR-xxxx 便于排查)。

## 13.5 帮助说明规范

- 帮助入口均为**本地资源**(本地 HTML/PDF 手册),不联网。
- 设置项的 ⓘ Tooltip 写"影响"而非"定义":说明"改这个会怎样",而非解释术语。
- "检查更新"提示"当前为离线模式,请访问官网比对版本",不自动联网。

## 13.6 Tooltip 编写规范

- 简短(最多两行),补充而非重复可见文字。
- 用于:长文件名全文、设置项影响、图标按钮含义。
- 不用于:传递关键信息(关键信息必须有可见文字)。

## 13.7 中文术语统一表

| 规范名(用这个)          | 通俗叫法/解释                    | 避免的说法                 |
| ----------------------- | -------------------------------- | -------------------------- |
| 拍摄信息（EXIF）        | 照片里隐藏的相机型号、时间、定位 | 元数据、EXIF 数据          |
| 颜色配置（ICC）         | 颜色管理信息                     | 色彩配置文件、ICC profile  |
| 基础式 JPEG（Baseline） | 一次性显示的 JPEG                | 基线 JPEG、baseline        |
| sRGB 色彩空间           | 兼容性最好的色彩空间             | 色彩配置、色彩空间(单独用) |
| HEIC                    | iPhone 默认的照片格式            | 高效图像格式、HEIF         |
| 兼容模式                | 针对某类系统的预设设置组         | 配置文件、profile          |
| 输出目录                | 处理结果保存的文件夹             | 目标路径、output           |
| 跳过                    | 不处理某个文件(损坏/不支持)      | 忽略、skip                 |
| 老旧系统                | 政务/医疗/教育等旧版上传系统     | 遗留系统、legacy           |

> 技术词（EXIF、ICC、HEIC、Baseline、sRGB、WebP、TIFF、GIF、BMP）在界面上保留英文原文,首次出现配通俗解释。

## 13.8 禁用词清单

界面任何位置**不得出现**以下字样(破坏离线信任与安全感):

| 禁用                 | 原因                        |
| -------------------- | --------------------------- |
| 登录 / 账号 / 注册   | 暗示需要身份,违背离线即信任 |
| 云 / 云端 / 云存储   | 暗示联网上传                |
| 上传 / 下载 / 同步   | 暗示网络传输                |
| AI / 智能 / 智能识别 | 暗示联网能力,制造不实预期   |
| 联网 / 在线 / 网络   | 与"离线"定位冲突            |
| 100% 成功 / 保证     | 过度承诺,违背诚实           |
| 请稍候(无说明)       | 无信息的等待话术            |

✅ **验收要点**:
- 全界面 0 处出现禁用词(登录/云/上传/AI/智能等)。
- 所有错误提示含四段结构(问题/原因/解决/按钮)。
- 按钮命名动词开头,2–6 字。
- 进度提示必配文字说明,不裸用进度条。
- 术语首次出现配通俗解释,其后统一用规范名。

# 14. 交互规则

> 本章是横切的统一交互反馈规则,与 §6 组件规格配合:组件规格定义"是什么",本章定义"所有交互的统一反馈"。

## 14.1 统一状态反馈表

| 状态     | 视觉变化                                                          | 时长      | 曲线 |
| -------- | ----------------------------------------------------------------- | --------- | ---- |
| Hover    | 主按钮加深 `#005293`;次/微妙按钮叠 `#F5F5F5`;可点击卡片微抬升阴影 | 100–120ms | ease |
| Pressed  | 主按钮再加深 `#003F73`;次/微妙叠 `#EDEDED`                        | 100ms     | ease |
| Focused  | 2px 强调色焦点环 + 2px offset                                     | 即时      | —    |
| Disabled | 50% 透明 + `not-allowed` 光标,不响应 Hover/Pressed                | —         | —    |
| Loading  | 文字→16px 环形进度,禁用点击                                       | 即时      | —    |

- **减少动画**:开启后所有过渡 ≤50ms 或即时;焦点环不消失。

## 14.2 拖拽（Dragging / Dropping）

| 阶段           | 反馈                                                                         |
| -------------- | ---------------------------------------------------------------------------- |
| 拖入窗口       | 拖拽区边框由 2px 虚线 → 2px 实线强调色,背景 `#E5F1FB`,文字"松开即可开始扫描" |
| 拖入非文件夹   | 拖拽区红字"请拖入文件夹,而不是单个文件"                                      |
| 拖入多个文件夹 | "一次只能处理一个文件夹"                                                     |
| 松开(合法)     | 自动开始扫描,过渡到扫描态                                                    |
| 松开(非法)     | 拖拽区恢复 Normal,提示停留 3s                                                |

- 拖拽仅在首页拖拽区生效;设置页与其他区域不响应拖拽。

## 14.3 选择（Selection）

| 场景           | 行为                                       |
| -------------- | ------------------------------------------ |
| 单选           | 点击选中;箭头键在列表内移动选中            |
| 多选(列表)     | Ctrl+点击追加;Shift+点击范围选;Ctrl+A 全选 |
| 筛选(扫描结果) | 点格式徽章/状态徽章即筛选该类              |
| 取消选择       | Esc 或点空白处                             |

## 14.4 多选（Multiple Selection）

- 扫描结果列表支持多选查看;批量场景少,多选主要用于"查看某类文件"。
- 全选复选框支持三态(未选/已选/半选)。

## 14.5 重试（Retry）

| 场景             | 行为                            |
| ---------------- | ------------------------------- |
| 扫描失败         | 错误卡[重试扫描],不自动重试     |
| 单文件处理失败   | 不自动重试,记日志 + 失败计数    |
| 整体失败(磁盘满) | 完成页[重试],清理空间后手动重试 |

- 原则:**不静默自动重试**(违背确定性),让用户主动决定。

## 14.6 撤销（Undo）

| 场景     | 行为                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 设置改动 | Ctrl+Z 撤销上一步 + "已撤销"微提示                                                  |
| 文件处理 | **不支持撤销**(已输出的 JPEG 不还原)——故默认输出到子目录、不覆盖,从源头避免需要撤销 |

## 14.7 取消（Cancel）

| 场景         | 行为                                   |
| ------------ | -------------------------------------- |
| 扫描         | [取消]回首页                           |
| 处理中       | [取消]→ §8.6 取消确认 → 已处理部分保留 |
| 弹窗/Flyout  | Esc 或点外部(Flyout)关闭               |
| 文件夹选择器 | Esc 取消选择器                         |

## 14.8 过渡动效总表

| 场景             | 动效                     | 时长     |
| ---------------- | ------------------------ | -------- |
| 按钮按下         | 背景色加深               | 100ms    |
| 拖拽悬停         | 边框/背景过渡            | 150ms    |
| 进度条填充       | 平滑跟进 + 数字等宽滚动  | 跟随实时 |
| 完成对勾         | 单次 stroke 绘制(仅一次) | 300ms    |
| 列表项 hover     | 背景变浅(不抬升)         | 120ms    |
| 可点击卡片 hover | 微抬升阴影               | 120ms    |
| 步骤切换         | 当前态迁移 + 内容淡入    | 150ms    |
| Toast            | 右下滑入/淡出            | 200ms    |
| 对话框           | 缩放 + 淡入              | 200ms    |

**禁用动效**:背景渐变流动、粒子、3D 翻转、常驻脉冲、视差滚动、开机炫酷动画。

✅ **验收要点**:
- Hover/Pressed/Focused 视觉反馈与状态表一致,过渡 100–120ms。
- 拖拽悬停边框/背景/文字三者同步变化。
- 不静默自动重试,重试由用户主动触发。
- 文件处理不支持撤销(故默认不覆盖)。
- 减少动画开启时过渡 ≤50ms,焦点环不消失。
- 界面无禁用动效(粒子/常驻脉冲/3D 翻转等)。

# 15. 边界情况

> 每类边界统一含:触发条件、表现、用户操作、文案、验收要点。本应用核心原则:**不静默跳过,全部显式告知**。

## 15.1 没有图片

| 项       | 内容                                                                      |
| -------- | ------------------------------------------------------------------------- |
| 触发     | 选定目录扫描后 0 张支持格式图片                                           |
| 表现     | 扫描结果空状态:"这个文件夹里没有可处理的照片" + 大图标 + [重新选择文件夹] |
| 用户操作 | 重新选择或返回首页                                                        |
| 文案     | "这个文件夹里没有可处理的照片"                                            |

## 15.2 全部是不支持格式

| 项       | 内容                                                                  |
| -------- | --------------------------------------------------------------------- |
| 触发     | 目录只有 PSD/RAW 等不支持格式                                         |
| 表现     | 扫描结果:总图片数 0 + InfoBar"检测到 N 个暂不支持的文件" + [点击查看] |
| 用户操作 | 查看清单 / 重新选择                                                   |
| 文案     | "检测到 N 个暂不支持的文件"(见 §5.8)                                  |

## 15.3 目录为空

| 项   | 内容                           |
| ---- | ------------------------------ |
| 触发 | 选定目录存在但无任何文件       |
| 表现 | 同 15.1 空状态                 |
| 文案 | "这个文件夹里没有可处理的照片" |

## 15.4 目录不存在

| 项       | 内容                                        |
| -------- | ------------------------------------------- |
| 触发     | 最近文件夹已被删除/移动,点[继续]时          |

# 16. 一致性规范

> 供走查用的横向检查清单。任何新增页面/组件/文案须通过以下 8 项一致性检查。

## 16.1 按钮层级一致性

- 每屏 Primary 主按钮至多 1 个。
- 同类操作跨页用同一按钮类型(如各页[取消]均为 Secondary)。
- 危险操作统一用 Destructive。

## 16.2 颜色一致性

- 强调色统一系统蓝;语义色成功绿/警告黄/错误红/信息蓝,全应用一致。
- 不引入规范外的颜色(无游离色值)。

## 16.3 图标一致性

- 全部 Fluent 线性风格,2px 描边,24/16px 尺寸。
- 同一概念用同一图标(如"文件夹"全应用同一图标)。
- 禁用表情符号作功能图标。

## 16.4 提示一致性

- 成功用 Toast,警告用 InfoBar,错误用弹窗——渠道不混用。
- 同类提示文案模板统一(如所有错误用四段结构)。

## 16.5 交互一致性

- Hover/Pressed/Focused 反馈全应用统一(见 §14.1)。
- Esc 全应用 = 返回/取消/关闭;Enter = 主行动。
- 危险操作全应用二次确认。

## 16.6 间距一致性

- 全部间距取 4 的倍数,使用令牌(xxs–xxl)。
- 同类元素间距跨页一致(如卡片间距 16,区块间距 24–32)。

## 16.7 命名一致性

- 按钮命名跨页一致([取消]、[继续] 不在不同页换成 [放弃]、[resume])。
- 术语用 §13.7 统一表,不混用同义词。

## 16.8 弹窗一致性

- 所有弹窗遵循四段结构 + 统一形态(8px 圆角、遮罩不关闭、焦点主按钮)。
- 危险类弹窗默认焦点在安全侧。

✅ **验收要点**(走查清单):
- [ ] 每屏 Primary 主按钮 ≤1 个。
- [ ] 全应用强调色与语义色一致,无游离色。
- [ ] 图标风格统一,同一概念同一图标。
- [ ] Hover/Pressed/Focused 反馈跨组件一致。
- [ ] Esc/Enter 行为全应用统一。
- [ ] 间距全部 4 的倍数。
- [ ] 按钮/术语命名跨页一致。
- [ ] 弹窗统一四段结构 + 形态。

# 17. 可扩展性

> 未来新增功能时,如何**不破坏现有信息架构**地接入。所有扩展遵循"默认隐藏,进阶可见"——不向普通用户暴露。

## 17.1 新的图片格式

- **接入点**:格式识别表 + 格式徽章字典 + 不支持格式对话框的支持列表。
- **影响面**:不破坏主流程;新格式自动出现在格式分布与"将转换"徽章中。
- **原则**:以增量方式支持(如 PSD/RAW/AVIF/DNG),不臃肿主程序。

## 17.2 新的兼容模式

- **接入点**:首页兼容模式徽章 Flyout + 设置-兼容性"预设管理"入口。
- **形态**:模式包(标准/医院/民政/学籍/自定义),可保存/导入。
- **影响面**:主流程不变,仅切换默认值组合。

## 17.3 批处理预设

- **接入点**:设置页或首页溢出菜单"预设"。
- **形态**:保存当前兼容+输出+性能设置为命名预设,一键切换。
- **影响面**:不破坏主路径,预设入口藏在设置。

## 17.4 批量重命名

- **接入点**:设置-输出分组,新增"文件命名规则"。
- **形态**:模板化命名(原名/序号/日期),默认"保持原名"。
- **影响面**:输出层增量,不影响主流程。

## 17.5 压缩模式

- **接入点**:兼容性分组,JPEG 质量已有;"目标体积"为可选扩展。
- **形态**:指定目标体积(如每张 < 200KB),自动调整质量。
- **影响面**:兼容选项增量。

## 17.6 深色模式

- **已内置**:主题"跟随系统/浅色/深色",令牌已含 Dark 色值(见 §12.1)。
- **扩展**:无需改架构,令牌切换即可。

## 17.7 国际化（i18n）

- **接入点**:文案抽取为资源键;界面语言下拉(默认简体中文)。
- **预留**:繁体/英文;字体栈已含跨语言回退。
- **注意**:文案避免生僻字(信创缺字);布局需适应文案长度变化。

## 17.8 插件系统

- **接入点**:高级分组"插件",以增量格式支持为主。
- **形态**:插件注册格式解码器,主程序不内置。
- **影响面**:主流程不变,插件失败不影响内置格式。

## 17.9 命令行模式

- **接入点**:无界面批处理,供 IT 部门批量部署/计划任务。
- **形态**:CLI 参数指定目录+模式+输出,复用处理内核。
- **影响面**:不影响 GUI;GUI 与 CLI 共用同一处理逻辑。

## 17.10 自动更新

- **接入点**:关于页"检查更新"。
- **形态**:**离线更新**——本地比对版本号,引导用户下载离线更新包,**不自动联网**。
- **原则**:守住离线即信任,不引入静默联网。

✅ **验收要点**:
- 所有扩展默认隐藏,普通用户主流程不受影响。
- 新格式/新模式接入不破坏主流程与信息架构。
- 深色模式与 i18n 通过令牌/资源切换,无需改架构。
- 自动更新不自动联网,守住离线定位。
- 命令行模式与 GUI 共用处理逻辑,不重复实现。

## 附录 A · 兼容性选项词典

> 兼容性分组(§5.6)每个选项的通俗解释、推荐值、默认值、潜在影响。措辞面向非技术用户。

| 选项                        | 解释(通俗)                                             | 推荐   | 默认   | 潜在影响                                             |
| --------------------------- | ------------------------------------------------------ | ------ | ------ | ---------------------------------------------------- |
| 移除拍摄信息（EXIF）        | 删除照片里记录的相机型号、拍摄时间、GPS 定位等隐藏信息 | 开     | 开     | 提升隐私;老系统常因这部分过大导致上传失败            |
| 移除颜色配置（ICC）         | 删除颜色管理信息                                       | 开     | 开     | 部分老系统不识别 ICC 会报错;移除后颜色可能极轻微变化 |
| 自动修正方向                | 根据拍摄时的方向把照片摆正                             | 开     | 开     | 避免 iPhone 照片在老系统里横倒显示                   |
| 转为基础式 JPEG（Baseline） | 把"渐进式 JPEG"(慢慢变清晰)转成"基础式"(一次性显示)    | 开     | 开     | 解决老系统只显示半张图的问题                         |
| 转换 HEIC                   | 把 iPhone 默认的 HEIC 格式转成 JPEG                    | 开     | 开     | 几乎所有老系统都不支持 HEIC,必须转                   |
| 转为 sRGB 色彩空间          | 统一为兼容性最好的色彩空间                             | 开     | 开     | 避免老系统色彩错乱                                   |
| JPEG 质量                   | 0–100,越高越清晰、文件越大                             | 90     | 90     | 90 兼顾画质与兼容;低于 75 可能肉眼可见模糊           |
| 最大宽度                    | 超宽图按此值缩小                                       | 4096px | 4096px | 老系统常拒绝超大图;设小可提升兼容与减小体积          |
| 最大高度                    | 同上                                                   | 4096px | 4096px | 同上                                                 |

✅ **验收要点**:
- 兼容性选项默认全部开启(移除 EXIF/ICC、修正方向、Baseline、转换 HEIC、sRGB)。
- JPEG 质量默认 90,范围 60–100,低于 75 有模糊风险提示。
- 最大宽高默认 4096px,超尺寸按此值缩小。
- 每个选项在设置页有通俗描述与影响说明。
