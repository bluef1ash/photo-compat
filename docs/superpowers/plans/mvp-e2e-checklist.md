# MVP 端到端验收清单

> 照片适配助手 MVP 骨架验收。自动化测试已全绿;GUI 主流程需人工按清单验证。

## 启动
- [ ] `cd backend && cargo tauri dev` 启动,窗口标题"照片适配助手",尺寸 1100×720(最小 880×640)
- [ ] 首页显示拖拽区 + [选择文件夹],状态栏"就绪 · 离线 v1.0"

## 主流程(端到端)
- [ ] [选择文件夹] → 系统选择器 → 选含 JPEG/PNG 的目录 → 扫描结果页显示总数 + 格式分布
- [ ] [开始处理] → 处理中页:大百分比 + 进度条 0→100% + 实时计数
- [ ] 完成页显示成功数 + [打开输出目录]
- [ ] [打开输出目录] 打开 `<源目录>/compat`,内为 `.jpg`,**原文件未改动**

## 边界场景
- [ ] 空目录 → 首页提示"这个文件夹里没有可处理的照片"(§15.1)
- [ ] 含损坏 JPEG → 处理完成,失败计数 +1,其余成功(§15.7)
- [ ] 含 HEIC → 跳过计数 +1,提示暂不支持(§10.13 MVP)
- [ ] 含 PSD → 扫描结果页提示不支持文件(§15.2)
- [ ] 二次处理同目录 → 不覆盖,输出加序号 `_1`(§15.8)

## 交互
- [ ] 处理中按 `Space` 暂停/继续(§5.4)
- [ ] [取消] 停止处理,已处理文件保留(§10.6)
