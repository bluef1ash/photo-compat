## 平台支持与跨平台策略

### 支持矩阵

| 平台         | 版本                                | 优先级    | 典型场景                     |
| ------------ | ----------------------------------- | --------- | ---------------------------- |
| Windows 11   | 21H2+                               | P0 主平台 | 政务 / 医疗 / 教育办公主力机 |
| Windows 10   | 1809+（含 LTSC）                    | P0        | 存量政务终端                 |
| Linux · 信创 | 统信 UOS / 麒麟 Kylin / deepin      | P1        | 党政信创国产替代             |
| Linux · 社区 | Ubuntu 22.04+ / Debian 12+ / Fedora | P2        | 技术用户、自部署             |

**WebView 运行时**：Windows 依赖 WebView2（Edge 内核，Win10/11 内置或随程序分发）；Linux 依赖 webkit2gtk（系统自带）。两者均为 Tauri 2.x 默认后端，**UI 代码无需为内核分叉**，三端共用同一套 React 组件与样式。

### 一致性策略：统一视觉 + 平台原生回退

产品定位是"低认知负担的政务工具"，**视觉与交互在各平台保持一致**，避免用户在 Win/Linux 间切换时重新学习。

| 层面                             | 策略                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| 色彩 / 间距 / 排版 / 圆角 / 组件 | **全平台统一**（本文档令牌），不跟随 GTK / Qt 主题色                                               |
| 字体                             | 统一栈，按平台回退到最接近的系统字体（见 §6.1）                                                    |
| 窗口背景 Mica                    | Win11 启用 Mica；Win10 / Linux 降级为纯色 `--bg`，卡片仍用 Layer 提升对比                          |
| 窗口标题栏                       | 默认应用自绘统一标题栏；提供"使用系统原生标题栏"开关，供 Linux CSD/SSD 或用户偏好原生装饰时回退    |
| 文件选择器 / 打开目录 / 消息框   | 调用各平台**原生**组件（Win = Win32 对话框；Linux = GTK FileChooser / `xdg-open`），保证用户熟悉感 |
| 修饰键                           | 全平台统一用 `Ctrl`（macOS 不在本期范围）                                                          |
| 托盘 / 通知                      | Win 原生托盘 + 任务栏闪烁；Linux 走 AppIndicator/SNI，桌面无托盘时优雅降级并自动隐藏该设置项       |

**总原则**：界面长得一样，原生能力（选文件夹、打开目录、通知）走系统。**禁止**为 Linux 单独设计一套 GTK 风格外观——会破坏跨平台一致性与品牌识别，徒增维护成本。

### Linux / 信创特别注意事项

1. **字体渲染**：信创系统多用思源黑体 / Noto Sans CJK SC，回退栈须包含；部分老国产系统缺字，文案避免生僻字。
2. **国产 CPU 架构**：龙芯（LoongArch）/ 飞腾 / 鲲鹏（ARM）需出对应架构安装包；性能档位偏低，**性能设置按架构自适应保守默认**（见 §26 性能分组）：ARM/LoongArch 默认并行数上限 4 且留 1 核给系统、内存上限取系统内存 50%、大图采样强制开启不可关。
3. **Wayland vs X11**：信创桌面（UOS/DDE）多为 X11，影响小；社区版 GNOME/KDE 趋向 Wayland，自绘标题栏需走 CSD，全局快捷键在 Wayland 沙箱下仅窗口内生效。
4. **权限模型**：UOS / 麒麟有自研权限管控（类 sudo 授权弹窗），访问非用户目录可能弹系统授权框——错误文案需兼容"系统拒绝了访问"。
5. **离线分发**：信创环境通常无应用商店联网，需提供 `.deb` / `.rpm` / UOS 安装包 + 全量离线依赖。
6. **托盘规范碎片化**：StatusNotifierItem (SNI) 与老式 XEmbed 并存，部分桌面（如纯 GNOME）无托盘——托盘功能标记为"可选"，缺失时优雅降级。
7. **路径分隔符**：内部统一用平台原生路径处理，UI 展示时保留用户习惯（Windows 反斜杠 `\`、Linux 正斜杠 `/`）。

## 一、设计基础

### 1. 整体设计哲学

**一句话哲学**：让最不懂电脑的人，也能放心地把"上传不了"的照片变成"一定能传"。

这个产品不是图像编辑器，不是云相册，不是 AI 工具。它是一把**只做一件事的瑞士军刀**：把一个文件夹里的照片，批量变成老旧政务/医疗/教育系统都能吃下的标准 JPEG。哲学围绕四条主线：

| 主线         | 含义                                     | 设计后果                                                         |
| ------------ | ---------------------------------------- | ---------------------------------------------------------------- |
| **确定性**   | 每个动作都有可预测结果，绝不"惊喜"       | 处理前显示预估数量与体积；处理中显示进度；处理后显示明确清单     |
| **安全感**   | 默认绝不破坏原始数据                     | 默认输出到子目录、默认不覆盖、默认保留结构；危险操作永远二次确认 |
| **诚实**     | 不夸大能力，不静默跳过                   | 不支持的格式、损坏的文件、失败项全部显式告知并记录               |
| **极简心智** | 用户只关心"传哪儿、点哪儿、在哪儿看结果" | 单一主路径、无侧栏、无多标签、无专业术语                         |

### 2. 五大设计原则

1. **三次点击原则（上限，非目标）**：从打开应用到打开输出目录，核心操作不超过 3 次点击；拖拽路径压到 2 次。任何把步骤加到 4 次以上的设计都要被质疑。
2. **单一主行动（One Primary Action）**：每个屏幕有且只有一个视觉权重最高的主按钮。其余操作降级为次按钮或微妙按钮。
3. **渐进披露（Progressive Disclosure）**：首页只给"拖进来/选文件夹"；统计、警告、设置按需展开。高级选项永远不挡主路径。
4. **可读性优先于美观**：字号偏大、间距偏宽、对比偏高。为视力下降的中老年办事员优化，而非为设计师审美优化。
5. **离线即信任**：界面任何位置不出现"登录、云、上传、AI、智能"等字样。状态栏常驻"离线"标识，强化安全感。

### 3. 信息架构

心智模型分三层，自上而下权重递减：

```
┌─────────────────────────────────────────────┐
│  主流程区（视口主体）                          │
│  选目录 → 扫描结果 → 处理 → 完成              │
│  任何时候占据 70% 以上视觉权重                  │
├─────────────────────────────────────────────┤
│  配置区（设置页，按需打开）                     │
│  通用 / 输出 / 兼容性 / 性能 / 外观 / 高级      │
│  默认值即可完成主流程，无需主动配置              │
├─────────────────────────────────────────────┤
│  辅助区（状态栏 + 通知 + 日志）                 │
│  当前状态、兼容模式、就绪/离线标识、Toast        │
└─────────────────────────────────────────────┘
```

**关键决策**：不使用 Fluent 的常驻 `NavigationView` 侧栏。这是一个**线性流水线工具**，不是多功能应用。常驻侧栏会制造"还有别的功能没看到"的认知负担，违背极简心智原则。导航用**顶部步骤指示器 + 右上溢出菜单**承载。

### 4. 导航结构

```
┌─ 标题栏（自定义，保留系统窗口控件）──────────────────────┐
│  [Logo] 照片适配助手   [标准兼容模式]        ⋯ 设置/关于/日志  │
├─ 步骤条（主流程进行时显示）─────────────────────────────┤
│  ① 选目录 ── ② 查看结果 ── ③ 处理 ── ④ 完成               │
├─ 主内容区（随步骤切换）────────────────────────────────┤
│                                                         │
│                                                         │
├─ 状态栏 ────────────────────────────────────────────────┤
│  ● 就绪      标准兼容模式 · 输出到 同目录/compat      离线 v1.0 │
└─────────────────────────────────────────────────────────┘
```

**导航规则**：
- 主流程四个步骤用**步骤条**而非面包屑或标签页——步骤条天然表达"线性、有进度、不可跳跃前进"。
- 步骤可**回退**（点已完成步骤返回），但**不可跳跃前进**（未扫描不能直接处理）。
- 设置、关于、日志通过右上 `⋯` 溢出菜单进入，不进入步骤条。
- `Esc` 永远表示"返回上一步 / 取消当前操作 / 关闭浮层"，是最强的安全出口。

## 二、视觉系统

### 5. 色彩系统

#### 5.1 强调色（Accent）

| 用途              | 色值（Light） | 色值（Dark） | 说明                            |
| ----------------- | ------------- | ------------ | ------------------------------- |
| Accent / Default  | `#0067C0`     | `#4CC2FF`    | Fluent 系统蓝。信任、专业、中立 |
| Accent / Hover    | `#005293`     | `#62B6FF`    | 加深 8%                         |
| Accent / Pressed  | `#003F73`     | `#7BD1FF`    | 再加深                          |
| Accent / Disabled | `#8AB8E8`     | `#3A5C7A`    | 与文字色 40% 混合               |
| Accent / 浅底填充 | `#E5F1FB`     | `#0A2B45`    | 选中态、徽章背景、拖拽悬停      |

**为什么是蓝色**：政务、医疗、教育场景中蓝色传达稳定与可靠；它是 Windows、GNOME 等主流桌面系统的常见强调色，三端用户都有天然熟悉感，降低"陌生软件"的戒备。**刻意避免**：绿色（易与"成功"语义混淆）、橙色/红色（报警意味）、紫色（不够正式）、品牌橙红（本项目关联品牌 `#f54900` 橙红虽辨识度高，但作为常驻 UI 强调色会持续传递"警告"信号，不利于安全感，故仅作为可选自定义强调色提供，不设为默认）。

#### 5.2 中性色（Light 主题）

| 语义                    | Token             | 色值                                                            |
| ----------------------- | ----------------- | --------------------------------------------------------------- |
| 窗口背景（Mica / 纯色） | `--bg`            | `#F3F3F3`（Win11 启用 Mica 时透出壁纸；Win10 / Linux 用此纯色） |
| 卡片/面板表面           | `--surface`       | `#FFFFFF`                                                       |
| 卡片表面（叠层）        | `--surface-alt`   | `#FAFAFA`                                                       |
| 前景文字 / 主           | `--fg`            | `#1A1A1A`                                                       |
| 前景文字 / 次           | `--fg-muted`      | `#5B5B5B`                                                       |
| 前景文字 / 三级、禁用   | `--fg-disabled`   | `#8A8A8A`                                                       |
| 边框 / 细               | `--border`        | `#E5E5E5`                                                       |
| 边框 / 强               | `--border-strong` | `#D1D1D1`                                                       |
| 分隔线                  | `--divider`       | `#EDEDED`                                                       |

#### 5.3 语义色（状态编码，均配图标，不仅靠颜色）

| 语义         | 主色      | 浅底      | 图标   |
| ------------ | --------- | --------- | ------ |
| Success 成功 | `#107C10` | `#DFF6DD` | ✓ 圆勾 |
| Warning 警告 | `#9D5D00` | `#FFF4CE` | ⚠ 三角 |
| Error 错误   | `#C42B1C` | `#FDE7E9` | ✕ 圆叉 |

#### 5.4 Dark 主题对应（要点）

窗口背景 `#202020`、卡片 `#2B2B2B`、前景 `#FFFFFF`/`#C5C5C5`、边框 `#3F3F3F`。主题切换**跟随系统**为默认，强调色与语义色按上表 Dark 列。

### 6. 排版系统

#### 6.1 字体栈

```css
/* UI 字体栈 —— 跨平台，按平台回退到最接近的系统字体 */
font-family: "Segoe UI Variable Text", "Segoe UI",        /* Windows 11/10 */
             "Cantarell", "Inter",                          /* Linux GNOME / 通用 */
             system-ui, sans-serif;
/* 中文 —— Windows 走雅黑，Linux 走思源 / Noto CJK */
font-family: "Microsoft YaHei UI", "Microsoft YaHei",      /* Windows */
             "Source Han Sans SC", "Noto Sans CJK SC",     /* Linux / 信创 */
             "PingFang SC", sans-serif;
/* 显示标题 */
font-family: "Segoe UI Variable Display", "Source Han Sans SC", "Microsoft YaHei UI", sans-serif;
/* 等宽（日志、路径、数字对齐） */
font-family: "Cascadia Code", "Consolas",                  /* Windows */
             "JetBrains Mono", "DejaVu Sans Mono",         /* Linux */
             ui-monospace, monospace;
/* 数字（统计/进度/大小）—— 等宽对齐 */
font-variant-numeric: tabular-nums;
```

**说明**：
- **不引入网络字体**（离线原则），全部使用各平台预装字体，按平台回退。
- **Windows**：Segoe UI Variable + 微软雅黑 UI（系统内置、渲染清晰、字形中性）。
- **Linux / 信创**：思源黑体（Source Han Sans）/ Noto Sans CJK SC（UOS、麒麟、deepin、Ubuntu 中文版标配）；西文回退 Cantarell（GNOME）/ Inter。
- 字体栈顺序保证：每平台优先命中本地最优字体，缺失时优雅降级，跨平台视觉重心一致（中性、清晰、非装饰性）。

#### 6.2 字号阶梯

| Token         | 字号    | 行高 | 字重 | 用途                          |
| ------------- | ------- | ---- | ---- | ----------------------------- |
| `caption`     | 12px    | 1.4  | 400  | 状态栏、辅助说明、时间戳      |
| `body`        | 14px    | 1.5  | 400  | 正文、控件文字（Fluent 默认） |
| `body-strong` | 14px    | 1.5  | 600  | 强调文字、按钮                |
| `subtitle`    | 20px    | 1.3  | 600  | 区块标题                      |
| `title`       | 28px    | 1.25 | 600  | 页面主标题                    |
| `large-title` | 40px    | 1.2  | 600  | 首页大字（慎用）              |
| `display-num` | 48–56px | 1.0  | 600  | 统计大数字（tabular-nums）    |

**字重只用 Regular 400 与 Semibold 600**，不用 Bold 700（Fluent 体系以 Semibold 表强调，过粗在小字号下糊）。`大字号` 辅助设置开启时，整套阶梯 ×1.25（或 ×1.5 超大）。

### 7. 间距系统

基于 **4px 基础栅格**（Fluent 原生栅格）。

| Token | 值   | 典型用途                     |
| ----- | ---- | ---------------------------- |
| `xxs` | 4px  | 图标与文字间距、紧凑控件内距 |
| `xs`  | 8px  | 控件内 padding、列表行内间距 |
| `s`   | 12px | 输入框内距、按钮内距（横向） |
| `m`   | 16px | 卡片内距、控件组间距         |
| `l`   | 24px | 区块内间距、页面边距（小窗） |
| `xl`  | 32px | 区块间距、页面边距（大窗）   |
| `xxl` | 48px | 首页大区块间距               |

**规则**：相邻元素间距取上一级 token；卡片之间 16，区块之间 24–32。所有间距取 4 的倍数，禁止 5/7/10 这类游离值。

### 8. 圆角与阴影（Elevation）

| 元素                          | 圆角      | 阴影                       |
| ----------------------------- | --------- | -------------------------- |
| 按钮 / 输入框 / 小控件        | 4px       | 无（用背景色变化表达状态） |
| 卡片 / 对话框 / 面板 / 拖拽区 | 8px       | 见下                       |
| 轮播/大容器                   | 8px       | —                          |
| 状态点 / 头像                 | 50%（圆） | —                          |

阴影层级（Fluent elevation）：
- **Rest**（卡片静置）：`0 2px 4px rgba(0,0,0,0.06)`
- **Hover**（列表项可悬停卡片）：`0 2px 8px rgba(0,0,0,0.08)`
- **Flyout / Dialog**（浮层/对话框）：`0 8px 16px rgba(0,0,0,0.14)`
- **Tooltip**：`0 4px 8px rgba(0,0,0,0.12)`

### 9. 视觉层级

通过**空间 > 对比 > 字号字重**三个杠杆建立，优先级从左到右。

首页层级金字塔（示例）：
1. **拖拽区**（最大面积 + 虚线强调边 + 浅强调底）→ 视觉权重最高
2. **[选择文件夹] 主按钮**（强调色实底 + 最大尺寸 48px 高）→ 主行动
3. **最近文件夹卡片**（白底 + 边框，中等）→ 次快捷
4. **处理说明 + 兼容模式徽章**（小字 + InfoBar）→ 辅助理解
5. **状态栏**（最浅、最底）→ 环境信息

**反模式禁令**：禁止用颜色给非主行动也做强对比；禁止多个元素同时"喊话"（一屏只有一个视觉焦点）。

### 10. 图标风格

- **来源风格**：Fluent System Icons（线性 outline，统一 2px 描边，圆角端点，几何对称）。24px 默认尺寸，16px 用于行内辅助。
- **禁用**：emoji 作功能图标、彩色立体拟物、手绘风、游戏化图标。
- **着色规则**：默认继承当前文字色；强调图标用 `--accent`；状态图标用对应语义色；装饰性图标用 `--fg-muted`。
- **无障碍**：所有图标按钮必须有 `aria-label` + tooltip；纯图标行必须配文字标签。
- **核心图标集**（必备）：文件夹、扫描（雷达）、开始（播放）、暂停、取消（×）、完成（✓）、警告（⚠）、错误（✕）、信息（i）、设置（齿轮）、日志（文档）、输出目录（文件夹-打开）、图片（相框）、刷新、搜索、拖拽（手柄）、问号（帮助）。

## 三、组件规范

> 每个组件给出：用途 · 外观 · 尺寸 · 状态 · 行为。除非注明，所有控件支持完整键盘操作与焦点环。

### 11. 组件总览

| 类别   | 组件                                                             |
| ------ | ---------------------------------------------------------------- |
| 行动类 | 按钮（Primary/Secondary/Subtle/Destructive）、图标按钮、分裂按钮 |

### 12. 按钮系统

| 类型                 | 外观                                  | 用途                                     |
| -------------------- | ------------------------------------- | ---------------------------------------- |
| Primary 主按钮       | 强调色实底 + 白字                     | 每屏唯一主行动（开始处理、打开输出目录） |
| Secondary 次按钮     | 白底 + 强调色或中性 1px 描边 + 中性字 | 次要操作（取消、导出日志）               |
| Subtle 微妙按钮      | 透明底，hover 浅灰                    | 工具栏、低频操作（打开日志文件）         |
| Destructive 危险按钮 | 红字描边或红底白字                    | 取消处理、删除、重置设置                 |
| 图标按钮 IconButton  | 40×40 方形，仅图标                    | 标题栏控件、行内操作                     |
| 分裂按钮 SplitButton | 主按钮 + 下拉箭头                     | "选择文件夹"展开最近目录                 |

**尺寸（高度）**：大 48px（首页主 CTA 专用）/ 标准 40px / 紧凑 32px。最小触摸目标 40×40。圆角 4px。横向内距 16px（大号 24px）。

**状态**：

| 状态     | 表现                                          |
| -------- | --------------------------------------------- |
| Normal   | 按类型定义                                    |
| Hover    | 主按钮加深 `#005293`；次/微妙按钮叠 `#F5F5F5` |
| Pressed  | 主按钮再加深 `#003F73`；过渡 100ms            |
| Focused  | 2px 强调色焦点环（offset 2px），不依赖颜色    |
| Disabled | 50% 透明 + `not-allowed` 光标，不响应 hover   |
| Loading  | 文字替换为 16px 环形进度 + 禁用点击           |

### 13. 输入与表单控件

| 控件        | 规格                              | 行为                                  |
| ----------- | --------------------------------- | ------------------------------------- |
| Toggle 开关 | 高 20，轨道宽 40，圆头；开=强调色 | 切换有 150ms 滑动，遵循"减少动画"可关 |

| Radio       | 20×20 圆，选中强调色实心点        | 组内单选                              |
| Slider 滑块 | 轨道高 4，滑块 24 圆              | JPEG 质量、最大宽高可选用             |

### 14. 卡片与统计卡

**卡片容器**：白底，8px 圆角，1px `--border` 边框，内距 16–24，可选 Rest 阴影。标题区（subtitle 字号）+ 内容区。

**统计卡**（核心数据展示组件）：
```
┌──────────────────────┐
│ 📁 图标               │
│                       │
│   230                 │  ← display-num 48px tabular
│   总图片数             │  ← caption muted
└──────────────────────┘
```
- 大数字必须 `tabular-nums`，避免跳动
- 数字变化时平滑滚动（≤200ms），遵循减少动画可关
- 可选副标题/单位/趋势箭头
- 状态色：失败卡红、跳过卡灰，点击可展开详情

**InfoBar 信息条**（页内常驻提示）：图标 + 标题 + 描述 + 可选操作按钮 + 关闭×。分 Info/Warning/Error/Success 四色。用于"检测到 8 张 HEIC 将自动转换"这类上下文提示。

### 15. 进度与加载

| 组件               | 规格                                                    | 场景                 |
| ------------------ | ------------------------------------------------------- | -------------------- |
| 线性进度（确定）   | 高 8px（处理页）/ 4px（紧凑），强调色填充，底 `#E5E5E5` | 处理进度、扫描进度   |
| 线性进度（不确定） | 同上，强调色流动动画                                    | 启动、扫描初期       |
| 环形进度           | 32–40px，强调色弧线                                     | 加载态、按钮 loading |
| 大百分比数字       | 56px tabular + 进度条                                   | 处理页主视觉         |

**规则**：进度条必须有文字说明当前在做什么（"正在扫描… 已发现 230 张"），不裸用。完成态用对勾图标替换进度条（单次绘制动画 300ms，仅一次）。

### 16. 列表与表格

**扫描结果详情列表**（非密集表格，照顾可读性）：
- 行高 48px，hover `#F5F5F5`，分组分隔线
- 列：缩略图 40×40（可选）· 文件名（截断 tooltip 全名）· 格式徽章 · 大小 · 状态徽章
- 支持按格式/状态筛选（顶部徽章点击即筛选）

**设置行**（Settings 页核心模式）：
```
标题（body-strong）                     [控件]
描述（caption muted）                   
[影响/推荐 tooltip ⓘ]
─────────────────────────────────────
```
左标题+描述，右控件，下方细分隔线。鼠标悬停 ⓘ 显示影响说明。

**表格**（日志、失败清单用）：等宽列，monospace 12px（日志），表头 sticky，斑马纹可选。

### 17. 对话框与浮层

**模态对话框 ContentDialog**（错误、确认、不支持图片）：
- 居中，8px 圆角，宽 448–548px
- 半透明遮罩 `rgba(0,0,0,0.3)`，遮罩点击**不**关闭（防误触，需显式按钮或 Esc）
- 结构：标题区（图标 + 标题）→ 内容区 → 按钮区（右下，主按钮在最右）
- 焦点默认落在主按钮，Tab 在对话框内循环
- 出现/消失 200ms 缩放+淡入（遵循减少动画可关）

**Flyout 轻量浮层**（快速设置、最近目录下拉）：
- 锚定触发控件，小箭头指向，8px 圆角，Flyout 阴影
- 点击外部或 Esc 关闭

**Tooltip**：悬停/聚焦 500ms 后出现，黑底白字（Light）/ 白底黑字（Dark），12px，最多两行，4s 自动消失。

**确认对话框**：标题 + 风险描述 + 主/次按钮。危险操作（取消处理、覆盖文件、重置设置）必走确认。

### 18. 通知与状态

- **Toast**（右下角，非模态）：成功/信息提示，自动 4–7s 消失，可手动×。例："已导出日志到桌面"。
- **InfoBar**（页内顶部嵌入）：需用户注意但不阻断的警告/提示，可关闭。
- **状态栏**（窗口底部常驻）：三段式——左"就绪/处理中/扫描中"（带状态点）· 中"兼容模式 · 输出位置"· 右"离线 · 版本号"。
- **徽章 Badge**：小标签，强调色浅底或语义色，标识格式、模式、状态。

### 19. 框架组件

- **标题栏**：高 40，默认自绘统一标题栏（Windows 保留系统圆角顶角与最小化/最大化/关闭按钮；Linux 自绘 CSD 控件）。左侧 Logo + 应用名；中部留空作为拖拽区；右侧兼容模式徽章 + `⋯` 溢出菜单（设置/关于/打开日志/最小化到托盘）。双击最大化。提供"使用系统原生标题栏"开关（Linux SSD 桌面 / 用户偏好原生装饰时回退）。
- **步骤条**：水平四步，已完成=对勾+强调色，当前=强调色实心数字，未到=灰。可点已完成步骤回退。当前步骤下方可显示子进度。
- **状态栏**：见上。
- **溢出菜单**：右上 `⋯`，纵向列表，每项图标+文字+快捷键提示。

### 20. 空状态与加载态

**空状态**模板：大图标（64px，`--fg-disabled`）+ 一句话标题 + 可选一句描述 + 可选主按钮。
- 首页无最近文件夹："还没有最近处理过的文件夹" + "把文件夹拖到上方区域，或点击选择文件夹"
- 扫描 0 张："这个文件夹里没有可处理的照片" + [重新选择文件夹]
- 设置搜索无果："没有匹配的设置项"

**加载态**模板：环形进度（32px）+ 动态文字说明（"正在扫描… 已发现 N 张"）。绝不让界面"白屏等待"——任何超过 200ms 的操作都要有加载指示。

## 四、页面设计（9 个屏幕）

> 每屏统一给出：**目的 · 布局 · 组件 · 交互 · 空状态 · 加载状态 · 错误状态 · 键盘快捷键**。

### 21. 屏幕一 · 首页 Home

**目的**：单一明确的入口。用户打开应用后 0.5 秒内知道"把文件夹弄进来"。

**布局**（垂直自上而下）：
1. **标题栏**：Logo + "照片适配助手" + 兼容模式徽章"标准兼容模式" + 右上 `⋯`
2. **欢迎语**（title 28px）："把照片变成任何老旧系统都能上传的格式" + 副标（body muted）："全程离线，不上传任何文件，安全放心"
3. **大拖拽区**（核心，约占视口高度 40%）：
   - 虚线边框（2px dashed `--border-strong`），8px 圆角，浅底 `#FAFCFF`
   - 中央：文件夹大图标（48px）+ "把包含照片的文件夹拖到这里" + 分隔"或" + **[选择文件夹]** 主按钮（48px 高，大号）
   - 拖拽悬停态：边框变 2px 实线强调色，背景 `#E5F1FB`，文字变"松开即可开始扫描"
4. **最近文件夹**（卡片列表，最多 5 个）：每项 = 文件夹图标 + 路径（截断）+ "上次处理：3 天前 · 230 张" + 右侧[继续]次按钮。整块无数据时隐藏。
5. **处理说明卡**（InfoBar 风格，可折叠）："会做什么：转成 JPEG · 去除拍摄信息 · 修正方向 · 转换 HEIC" + 右侧[查看/修改]链接到设置-兼容性
6. **状态栏**：● 就绪 | 标准兼容模式 · 输出到 同目录/compat | 离线 v1.0

**组件**：拖拽区、主按钮、列表卡片、InfoBar、状态栏、徽章。

**交互**：
- 拖入文件夹 → 自动开始扫描（**无需点确认**）
- 点[选择文件夹] → 系统原生 FolderPicker → 选定后自动扫描
- 点最近文件夹卡片或[继续] → 直接对该目录扫描
- 点兼容模式徽章 → 弹出 Flyout 快速切换模式（标准/医院/民政/自定义）
- 拖入单个文件或非文件夹 → 拖拽区内红色提示"请拖入文件夹，而不是单个文件"

**空状态**：首次启动无最近文件夹 → 隐藏最近区域，拖拽区下方显示引导文字"第一次使用？把任意一个照片文件夹拖到上方即可"。

**加载状态**：选定文件夹后立即过渡到扫描态——首页主体淡出（150ms），步骤条出现"①选目录 ✓ → ②扫描中…"，主内容区显示环形进度 + "正在扫描 文件夹名… 已发现 N 张"。

**错误状态**：目录不可读 → 顶部红色 InfoBar"无法读取这个文件夹"+ [重新选择]，拖拽区恢复可用。

**键盘快捷键**：
- `Ctrl+O` 选择文件夹
- `Ctrl+1`～`Ctrl+5` 打开第 1～5 个最近文件夹
- `Tab`/`Shift+Tab` 在拖拽区、按钮、最近项间移动
- `Enter` 拖拽区聚焦时 = 选择文件夹
- `Esc` 无操作（已在起点）

### 22. 屏幕二 · 文件夹选择 Folder Selection

**目的**：让用户指定要处理的目录，提供"系统选择器"和"最近列表"两条路径。

**布局说明**：本屏**不单独占据整页**。点击[选择文件夹]直接调用**各平台原生文件夹选择器**（Windows = Win32 FolderPicker；Linux = GTK FileChooser），无需自行设计界面，保证用户对系统选择器的熟悉感。最近文件夹的快捷选择已内嵌在首页。

补充设计：选定后、扫描前若发现该目录无可处理图片，显示轻量 Flyout"这个文件夹里没有可处理的照片"+ [重新选择]。

**组件**：FolderPicker（系统）、首页内嵌的最近列表卡片。

**交互**：
- FolderPicker 中选定 → 立即校验可读 → 通过则扫描；不通过弹错误对话框
- 拖拽同样进入此流程（拖拽是 FolderPicker 的替代入口）

**空状态**：无最近文件夹时，[选择文件夹]下方提示"也可以直接把文件夹拖到窗口里"。

**加载状态**：选定后立即扫描，进入扫描过渡态。

**错误状态**：权限不足 / 目录无效 → 见屏幕七错误对话框。

**键盘快捷键**：`Ctrl+O` 打开选择器，`Esc` 取消选择器，`Enter` 在选择器中确认。

### 23. 屏幕三 · 扫描结果 Scan Result

**目的**：处理前让用户清楚知道"会发生什么"——处理多少、产出多大、有无问题。**确定性原则的关键落点**。

**布局**：
1. **步骤条**：①选目录 ✓ → ②查看结果（当前）→ ③处理 → ④完成
2. **标题区**："扫描完成"（title）+ 源目录路径（可点击"← 重新选择"）
3. **统计卡网格**（4 列，窄屏 2 列）：
   - 总图片数 `230`
   - 预计输出数量 `230`
   - 预计输出大小 `约 48 MB`
   - 预计节省 `减少 12 MB`（原始 60MB → 48MB）
4. **格式分布卡**（徽章组 + 横条）：
   ```
   JPEG ████████████████ 202   PNG ███ 15   HEIC ██ 8
   WebP █ 3   GIF █ 2   TIFF ▏1   BMP 0
   ```
   每格式 = 图标 + 名称 + 数量；HEIC 等需转换的徽章带"将转换"小标签高亮。
5. **兼容性问题与警告**（InfoBar 列表）：
   - 🟡 检测到 8 张 HEIC（iPhone 照片），将自动转换为 JPEG
   - 🟡 15 张 PNG 体积较大，转换后通常更小
   - 🔴 3 张图片疑似损坏，将被跳过并记录到日志
6. **输出设置快览**（一行卡片）：输出到「同目录/compat 文件夹」· 保留结构 · 不覆盖 · 质量 90 + [修改]链接（弹 Flyout，不离开页面）
7. **底部操作栏**（固定/sticky）：左"共 230 张，预计输出约 48 MB" | 右 **[开始处理]** 主按钮 + [取消] 次按钮

**组件**：步骤条、统计卡、格式徽章、InfoBar、底部操作栏、Flyout 快速设置。

**交互**：
- 点格式徽章 → 展开该格式文件子列表（进阶，默认折叠）
- 点警告 InfoBar → 展开详情与影响
- 点[修改]输出设置 → Flyout 快速改输出位置/覆盖策略（深度设置仍去设置页）
- [开始处理] → 进入处理页

**空状态**：扫描到 0 张 → 居中"这个文件夹里没有可处理的照片" + 大图标 + [重新选择文件夹]。

**加载状态**：扫描中 → 环形进度 + "正在扫描… 已发现 N 张"（实时刷新计数）。

**错误状态**：扫描失败（如中途权限丢失）→ 居中错误卡 + [重试扫描]。

**键盘快捷键**：`Enter` 开始处理，`Esc` 返回首页，`Tab` 遍历统计卡与警告。

### 24. 屏幕四 · 处理中 Processing

**目的**：让用户安心等待，清楚知道进度与健康度。

**布局**：
1. **步骤条**：①✓ ②✓ → ③处理中（带子进度）→ ④完成
2. **大进度区**（主视觉）：
   - 大百分比 `68%`（display-num 56px tabular）
   - 线性进度条（8px 高，全宽，强调色填充）
   - 副文字"已处理 156 / 230"
3. **当前文件**行：缩略图 40×40 + 文件名（截断 tooltip 全名）+ 当前操作徽章"转换 HEIC → JPEG"
4. **实时统计**（6 个统计卡，3×2 或 6×1）：
   - 已用时间 `00:42`
   - 预计剩余 `01:20`
   - 速度 `3.6 张/秒`
   - 已处理 `156`
   - 失败 `0`（>0 变红，可点查看）
   - 跳过 `0`（>0 变灰，可点查看）
5. **实时日志**（可折叠面板）：
   - 默认折叠为一行"最新：[14:23:05] 转换 IMG_0123.HEIC → JPEG ✓"
   - 展开后为滚动列表，monospace 12px，带时间戳与状态色
6. **底部操作栏**：[暂停]（次按钮，暂停后变[继续]）| [取消]（危险按钮）| [打开日志文件]（微妙按钮）

**组件**：步骤条、大进度条、统计卡、徽章、可折叠日志面板、操作栏。

**交互**：
- [暂停] → 进度条变灰、计数暂停、按钮变[继续]、状态栏"已暂停"
- [取消] → 弹确认对话框"已处理的 156 张会保留在输出目录，确定取消吗？" → 是则停止并跳到完成页（带"已取消"标记）
- 失败/跳过计数 > 0 → 该统计卡高亮，点击弹出失败/跳过清单
- 日志面板点击标题栏展开/折叠
- 失败数超阈值（如 >5% 或 >20 张）→ 顶部黄色 InfoBar"失败较多，建议查看日志后再决定是否继续"

**空状态**：不适用（进入此屏必然有任务）。

**加载状态**：本屏即为处理态；进入瞬间（<200ms）显示"准备中…"不确定进度条再切确定进度。

**错误状态**：单文件失败 → 记日志 + 失败计数 +1 + 不中断主流程；磁盘满等致命错误 → 弹错误对话框 + 停止 + 跳完成页（未完成态）。

### 31. 微交互与动效

**克制原则**：动画仅用于**反馈状态变化**，绝不作装饰。时长 100–200ms，缓动 `ease` / `ease-out`。全部遵循"减少动画"设置（开则 ≤50ms 或即时）。

| 场景                         | 动效                           | 时长     |
| ---------------------------- | ------------------------------ | -------- |
| 按钮按下                     | 背景色加深                     | 100ms    |
| 拖拽悬停                     | 边框/背景过渡                  | 150ms    |
| 进度条填充                   | 平滑跟进 + 数字 tabular 滚动   | 跟随实时 |
| 完成对勾                     | 单次 stroke 绘制（仅一次）     | 300ms    |
| 列表项 hover                 | 背景色变浅（不抬升，避免抖动） | 120ms    |
| 卡片 hover（可点击卡片）     | 微抬升阴影                     | 120ms    |
| 步骤切换                     | 步骤条当前态迁移，内容淡入     | 150ms    |
| Toast                        | 右下滑入 / 淡出                | 200ms    |
| 对话框                       | 缩放 + 淡入                    | 200ms    |
| 错误呼吸（致命错误未处理时） | 图标轻微脉冲（仅 2 次）        | —        |

**禁用动效**：背景渐变流动、粒子、3D 翻转、常驻脉冲、视差滚动、开机炫酷动画。

### 32. 响应式行为（窗口尺寸）

桌面应用"响应式"= 窗口缩放自适应，非移动端断点。

| 窗口宽度             | 布局调整                                                         |
| -------------------- | ---------------------------------------------------------------- |
| `< 960px`（紧凑）    | 统计卡 4 列 → 2 列；设置左侧导航折叠为顶部下拉；标题栏应用名截断 |
| `960–1280px`（标准） | 默认布局，推荐工作区                                             |
| `> 1280px`（宽屏）   | 内容区最大宽 1200px 居中，两侧留白；不无限拉伸防止行宽过长       |
| 最小窗口             | **880×640**，保证核心元素不挤压、不溢出、不重叠                  |

**字号缩放**：跟随"大字号"设置整体 ×1.25 / ×1.5，布局自适应不溢出、不裁切。

**禁止**：任何宽度下出现横向滚动条；大数字、长文件名溢出单元格（一律截断 + tooltip 全文）。

### 33. 桌面窗口行为

**通用行为（全平台一致）**：
- **单实例**：再次启动激活已有窗口，不开第二实例。
- **关闭确认**：处理进行中关闭 → 确认对话框"处理尚未完成（已完成 68%），确定退出吗？[继续处理] [退出]"。
- **窗口记忆**：记住上次位置、大小、主题。
- **拖拽接受**：仅接受文件夹拖拽；拖入文件提示"请拖入文件夹"；拖入多个文件夹提示"一次只能处理一个文件夹"。
- **全屏/最大化**：内容居中限宽，不铺满导致行宽失控。

**平台差异**：

| 行为         | Windows 10/11                                                  | Linux（含信创）                                                                         |
| ------------ | -------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 标题栏       | 默认自绘，保留系统圆角顶角与最小化/最大化/关闭控件；双击最大化 | 默认自绘 CSD 控件；提供"系统原生标题栏(SSD)"开关适配 GNOME/KDE/UOS/DDE                  |
| 窗口背景     | Win11 启用 Mica（透出桌面壁纸柔和色调）；Win10 降级纯色 `--bg` | **不支持 Mica**，统一使用纯色 `--bg` + 卡片 Layer 提升对比                              |
| DPI 缩放     | 100 / 125 / 150 / 200%，文字图标清晰锐利                       | 跟随 X11 分数缩放或 Wayland 缩放因子；自测 100 / 125 / 150%                             |
| 最小化到托盘 | 原生托盘 + 任务栏闪烁；可选（设置开关）                        | 走 AppIndicator / SNI；**桌面无托盘支持时**（如纯 GNOME）自动隐藏该设置项并禁用通知闪烁 |
| 打开输出目录 | 调用资源管理器 `explorer` 并选中文件                           | 调用 `xdg-open`（或信创对应文件管理器）                                                 |
| 文件夹选择   | Win32 FolderPicker                                             | GTK FileChooser                                                                         |
| 全局快捷键   | `Ctrl` 系列原生支持                                            | `Ctrl` 一致；Wayland 下全局快捷键受限，仅窗口激活后生效                                 |

**Wayland 特别说明**：自绘标题栏拖拽需通过 CSD；全局快捷键在 Wayland 沙箱下可能失效，应用需检测会话类型（X11/Wayland）并降级——窗口激活后快捷键仍可用。信创桌面（UOS/DDE）多为 X11，影响较小。

**托盘与快捷键降级策略**（本期决策）：
- **托盘能力探测顺序**：AppIndicator → SNI(StatusNotifierItem) → XEmbed → 无。命中任一即启用托盘（图标 + 右键菜单：打开 / 暂停 / 退出 + 设置项"最小化到托盘"）；全部缺失（如纯 GNOME 默认）则**完全隐藏**托盘相关 UI（设置项 + 标题栏溢出菜单项同步消失），完成通知改用 **应用内 Toast + 任务栏 urgency 提示**。托盘是增强项，缺失时主流程完全不受影响。
- **快捷键作用域**：全部快捷键在**窗口激活态**生效；后台 / 失焦**不注册全局快捷键**（规避 Wayland 权限申请的复杂度）。用户后台操作路径：点任务栏 / 托盘激活窗口 → 使用快捷键。
- **不向用户暴露** SNI / XEmbed 等底层碎片化，用户只感知"有 / 无托盘"。

## 六、无障碍与扩展

### 35. 无障碍设计（Accessibility）

本产品用户包含大量中老年、视力受限、操作不熟练群体，无障碍是**一等需求**而非附加项。

| 维度              | 要求                                                                                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **键盘可达**      | 100% 操作有键盘等价；逻辑 Tab 顺序（左上→右下，符合阅读顺序）；可见焦点环 2px 强调色（不依赖颜色），"减少动画"下不消失                                                                                   |
| **屏幕阅读器**    | 全语义角色（role/aria-label）；进度条 `role="progressbar"` + `aria-valuenow`；统计卡 `aria-label="总图片数 230"`；图标按钮必有 `aria-label`+tooltip；动态变化用 `aria-live`（进度、Toast、错误）即时播报 |
| **对比度**        | 正文 ≥ 4.5:1，大字 ≥ 3:1（WCAG AA）；状态编码不依赖颜色（图标+文字双重编码）                                                                                                                             |
| **色盲友好**      | 成功/失败/警告同时用颜色+图标+文字；红绿不并用作唯一区分                                                                                                                                                 |
| **高对比度**      | 跟随系统高对比度主题（Windows 高对比度 / Linux GTK 高对比度），控件边框加粗，背景纯化                                                                                                                    |
| **大字号**        | 提供 标准/大/超大 三档，布局自适应不溢出                                                                                                                                                                 |
| **减少动画**      | 跟随系统"减少动画"，开启后过渡 ≤50ms                                                                                                                                                                     |
| **触摸/点击目标** | ≥ 40×40（桌面），最小点击距离充足，主要按钮放大到 48                                                                                                                                                     |
| **错误提示**      | 内联 + aria-live，不仅靠颜色与图标                                                                                                                                                                       |
| **表单**          | label 显式关联控件；必填有标识；错误有文字说明                                                                                                                                                           |
| **认知负荷**      | 一屏一主行动；术语去技术化；危险操作二次确认；可撤销                                                                                                                                                     |

### 36. 未来可扩展性

设计预留以下扩展点，不破坏现有信息架构：

1. **兼容模式预设**：可保存/导入模式包（如"民政系统专用""医院 HIS 专用""学籍系统专用"），首页徽章可切换。设置页兼容性分组预留"预设管理"入口。
2. **自定义转换规则**：进阶用户定义"按尺寸分桶""按格式分流"等规则，藏在高级分组。
3. **命令行模式**：无界面批处理，供 IT 部门批量部署/计划任务。不影响 GUI。
4. **配置集中部署**：导入/导出配置 + 静默安装参数，便于单位统一下发。
5. **离线更新包**：本地比对版本号，引导用户下载离线更新包（不自动联网）。
6. **处理历史**：记录历次处理的时间/数量/模式，首页"最近文件夹"可扩展为"历史记录"面板。
7. **更多格式**：PSD / RAW / DNG / AVIF 等以插件形式增量支持，不臃肿主程序。
8. **多语言**：预留 i18n，繁体/英文。
9. **轻量统计仪表盘**：累计处理量、节省空间，作为完成页的可选折叠区，不喧宾夺主。

所有扩展遵循"默认隐藏，进阶可见"——不向普通用户暴露。

### 37. 潜在的可用性改进（建议优先级）

| 优先级 | 改进                                                     | 价值                                 |
| ------ | -------------------------------------------------------- | ------------------------------------ |
| P0     | 首页"先试一下"内置示例文件夹                             | 让用户零风险体验完整流程，建立信任   |
| P0     | 处理前 1–2 张样张的"转换前后"对比预览                    | 可视化证明"会变成什么样"，强化确定性 |

## 附录 B · 错误处理矩阵

| 错误类型         | 问题（一句话）             | 可能原因                          | 建议解决                                                       | 按钮                                 |
| ---------------- | -------------------------- | --------------------------------- | -------------------------------------------------------------- | ------------------------------------ |
| **目录不可访问** | 无法读取这个文件夹         | 文件夹已移动/删除；被其他程序锁定 | ① 确认文件夹存在 ② 关闭占用程序 ③ 重新选择                     | [重新选择] [打开帮助] [关闭]         |
| **权限不足**     | 没有权限访问这个文件夹     | 系统访问控制限制                  | ① 以管理员身份运行 ② 在文件夹属性中授予读取权限 ③ 换一个文件夹 | [重新选择] [打开帮助] [关闭]         |
